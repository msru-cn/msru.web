# P2 — 内容运行时化实施计划（内容更新不重新 build）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让内容更新（GitHub 远程 MDX / 数据库结构化数据）**不需要重新 build/部署**即可生效。混合策略：结构化数据走实时读取+缓存，长文 MDX 走 ISR 按需重验证。

**Architecture:** 现状是纯本地 SSG（`generateStaticParams` + `revalidate=false`，全部构建期固化）。本计划新增两条运行时内容通道：(1) `lib/content/remote-mdx.ts` 从 GitHub raw 拉取 MDX 并用 `unstable_cache` + tag 缓存 + 运行时编译；(2) `lib/content/products-repo.ts` 从数据库读产品/定价结构化数据并缓存；并加一个 `/api/revalidate` webhook 端点，内容源更新后打 tag 失效。文档动态路由从纯 SSG 改为 ISR（`revalidate` 秒/分钟级 + `dynamicParams`）。

**Tech Stack:** Next.js 16 App Router（`unstable_cache`、`revalidateTag`、`export const revalidate`）, Fumadocs 内容源, `@fumadocs/mdx-remote`（或 `next-mdx-remote`）运行时编译, zod 校验。

## Global Constraints

- 前置：P0 完成（可独立运行）。P1 非强依赖，可并行，但建议 P1 后做。
- 核心判据：修改 GitHub 上一篇 MDX 或数据库一条产品数据后，**不触发 `pnpm build`/重新部署**，页面在约定时效内反映更新（数据近实时；文档秒~分钟级 ISR）。
- 不破坏现有本地 docs：现有 `content/docs` 本地文档路径继续可用；远程内容是新增通道，不是替换。
- 缓存 tag 命名：文档 `mdx:<slug>`；产品数据 `products`、`pricing`。
- 环境变量新增：`CONTENT_REPO`（GitHub owner/repo）、`CONTENT_BRANCH`、`CONTENT_GITHUB_TOKEN`（可选私有仓）、`REVALIDATE_SECRET`、`DATABASE_URL`。全部进 `.env.example`（占位值），真实值不入 git。
- 数据库选型：本计划以 Postgres + `postgres`（porsager）驱动为默认实现（与 msru 平台栈一致）；若最终接入其它库，只需替换 `lib/db.ts` 一个文件，其余不变。
- TDD：数据解析、缓存 key、webhook 鉴权用单测；运行时 MDX 编译用集成验证。

```ts
import { compileMDX } from "@fumadocs/mdx-remote";
import { unstable_cache } from "next/cache";
import type { ReactNode } from "react";

export interface RemoteRepoConfig {
  repo: string;
  branch: string;
}

export interface RemoteDoc {
  title: string;
  description?: string;
  body: ReactNode;
  raw: string;
}

function repoConfig(): RemoteRepoConfig {
  return {
    repo: process.env.CONTENT_REPO ?? "supesthero-cmd/msru.platform",
    branch: process.env.CONTENT_BRANCH ?? "master",
  };
}

export function buildRawUrl(slug: string, cfg: RemoteRepoConfig): string {
  return `https://raw.githubusercontent.com/${cfg.repo}/${cfg.branch}/${slug}.mdx`;
}

export function cacheTagFor(slug: string): string {
  return `mdx:${slug}`;
}

async function rawFetcher(slug: string): Promise<string | null> {
  const url = buildRawUrl(slug, repoConfig());
  const token = process.env.CONTENT_GITHUB_TOKEN;
  const res = await fetch(url, {
    headers: token ? { Authorization: `Bearer ${token}` } : undefined,
  });
  if (!res.ok) return null;
  return res.text();
}

export async function fetchRemoteMdxRaw(slug: string): Promise<string | null> {
  const cached = unstable_cache(() => rawFetcher(slug), ["remote-mdx", slug], {
    tags: [cacheTagFor(slug)],
    revalidate: 3600,
  });
  return cached();
}

export async function compileRemoteMdx(slug: string): Promise<RemoteDoc | null> {
  const raw = await fetchRemoteMdxRaw(slug);
  if (raw == null) return null;
  const compiled = await compileMDX({ source: raw });
  const fm = compiled.frontmatter as { title?: string; description?: string };
  return {
    title: fm.title ?? slug,
    description: fm.description,
    body: compiled.body,
    raw,
  };
}
```

```tsx
  params,
}: {

}) {

      {doc.body}

}
```

写 `/Users/mac_1/msru.web/lib/content/products-repo.ts`：
```ts
import { unstable_cache } from "next/cache";
import { z } from "zod";
import { db } from "@/lib/db";

export interface ProductRecord {
  slug: string;
  title: string;
  tagline: string;
  description: string;
  accentColor: string;
  icon: string;
}

const RowSchema = z.object({
  slug: z.string(),
  title: z.string(),
  tagline: z.string(),
  description: z.string(),
  accent_color: z.string(),
  icon: z.string(),
});

export function parseProducts(rows: unknown[]): ProductRecord[] {
  const out: ProductRecord[] = [];
  for (const row of rows) {
    const parsed = RowSchema.safeParse(row);
    if (!parsed.success) continue;
    const r = parsed.data;
    out.push({
      slug: r.slug,
      title: r.title,
      tagline: r.tagline,
      description: r.description,
      accentColor: r.accent_color,
      icon: r.icon,
    });
  }
  return out;
}

async function fetchProducts(): Promise<ProductRecord[]> {
  const rows = await db()`SELECT slug, title, tagline, description, accent_color, icon FROM marketing_products ORDER BY sort_order`;
  return parseProducts(rows as unknown[]);
}

export async function getProducts(): Promise<ProductRecord[]> {
  const cached = unstable_cache(fetchProducts, ["products"], { tags: ["products"], revalidate: 300 });
  return cached();
}
```

```ts
import { revalidateTag } from "next/cache";
import { NextResponse } from "next/server";
import { isAuthorized } from "@/lib/content/revalidate-auth";

export async function POST(req: Request) {
  if (!isAuthorized(req, process.env.REVALIDATE_SECRET)) {
    return NextResponse.json({ ok: false, error: "unauthorized" }, { status: 401 });
  }
  const body = (await req.json().catch(() => ({}))) as { tag?: string; slug?: string };
  const tag = body.tag ?? (body.slug ? `mdx:${body.slug}` : null);
  if (!tag) {
    return NextResponse.json({ ok: false, error: "missing tag or slug" }, { status: 400 });
  }
  revalidateTag(tag);
  return NextResponse.json({ ok: true, revalidated: tag });
}
```
