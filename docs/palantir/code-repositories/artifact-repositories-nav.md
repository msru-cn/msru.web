# [](https://www.palantir.com/docs/foundry/code-repositories/artifact-repositories-nav/#navigation)Navigation

Before working with Artifacts, we recommend familiarizing yourself with the Artifact Repository interface.

There are three tabs at the top of the Artifact Repositories interface:

*   Search
*   Publish
*   Overview

## [](https://www.palantir.com/docs/foundry/code-repositories/artifact-repositories-nav/#search)Search

![Image 4: AR interface Search tab](https://www.palantir.com/docs/resources/foundry/code-repositories/ar-ui-search.png)

Search for Artifacts in your Artifact repository using the dropdown menu and search bar. Select a search result to view metadata such as version history, size, and creation date.

## [](https://www.palantir.com/docs/foundry/code-repositories/artifact-repositories-nav/#publish)Publish

![Image 5: AR interface Publish tab](https://www.palantir.com/docs/resources/foundry/code-repositories/ar-ui-publish.png)

[Publish Artifacts](https://www.palantir.com/docs/foundry/code-repositories/publish-artifact/) to your Artifact repository by generating a token and following step-by-step instructions in the **Instructions** section of the page.

## [](https://www.palantir.com/docs/foundry/code-repositories/artifact-repositories-nav/#overview)Overview

![Image 6: AR interface Overview tab](https://www.palantir.com/docs/resources/foundry/code-repositories/ar-ui-overview.png)

View a summary of all the Artifacts in your Artifact repository, including metadata like its resource ID (RID), creation date, and parent folder in your filesystem.
