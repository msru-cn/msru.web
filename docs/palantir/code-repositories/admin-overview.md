# [](https://www.palantir.com/docs/foundry/code-repositories/admin-overview/#administer-repositories)Administer repositories

Administration of code repositories requires the appropriate permissions. Most settings can be adjusted by repository **owners** (by default). Other options, like the code editor preferences, are available to all authors.

To change the settings of your Code Repository, access the repository and select **Settings** in the top navigation bar. The settings tab allows you to set your personal editor preferences as well as configure the behavior of the repository. See additional information on the following settings:

*   [Branch settings](https://www.palantir.com/docs/foundry/code-repositories/branch-settings/)
*   [Repository settings](https://www.palantir.com/docs/foundry/code-repositories/repository-settings/)
*   [Repository upgrades](https://www.palantir.com/docs/foundry/code-repositories/repository-upgrades/)
*   [Spark](https://www.palantir.com/docs/foundry/code-repositories/spark-profiles/)
*   [Artifacts](https://www.palantir.com/docs/foundry/code-repositories/artifact-settings/)
*   [Project scope](https://www.palantir.com/docs/foundry/code-repositories/use-project-references/)
*   [Security Approvals](https://www.palantir.com/docs/foundry/building-pipelines/remove-inherited-markings/#approval-modes)
*   [Additional repository settings (`repoSettings.json`)](https://www.palantir.com/docs/foundry/code-repositories/advanced-settings/)
