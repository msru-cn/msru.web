# [](https://www.palantir.com/docs/foundry/code-repositories/overview/#code-repositories)Code Repositories

To edit and manage your code in a familiar IDE, try [VS Code workspaces](https://www.palantir.com/docs/foundry/vs-code/overview/) and the [Palantir extension for Visual Studio Code](https://www.palantir.com/docs/foundry/vs-code/overview/).

**Code Repositories** provides a web-based integrated development environment (IDE) for writing and collaborating on production-ready code in Foundry. The application provides a user-friendly way to interact with the underlying Git repository, and provides a range of additional features:

*   All common Git version control tasks, including branching, committing, and tagging releases can be performed through the web UI
*   Repositories have integrated support for code review and collaboration through _pull requests_, including support for highly configurable permissions to ensure the codebase is high-quality
*   Every repository type includes integrated features to aid with the code authoring experience, including IntelliSense, code linting and error checking, and rich help dialogs

## [](https://www.palantir.com/docs/foundry/code-repositories/overview/#repository-types)Repository types

Code Repositories support creating repositories of many types. The most common repository types are described below.

*   **Transforms** repositories support authoring data transformation logic, and include features to enable previewing and debugging transforms. Supported languages include [Python](https://www.palantir.com/docs/foundry/transforms-python/overview/), [Java](https://www.palantir.com/docs/foundry/transforms-java/overview/), and [SQL](https://www.palantir.com/docs/foundry/transforms-sql/overview/)
*   [**Functions**](https://www.palantir.com/docs/foundry/functions/overview/) repositories enable writing business logic that can be executed with low latency in an operational context, and include native support for accessing data from the Foundry [Ontology](https://www.palantir.com/docs/foundry/ontology/overview/). The Code Repositories environment supports autocomplete based on Ontology data types, and enables code authors to preview Functions while authoring them. Functions can be written in [TypeScript](https://www.palantir.com/docs/foundry/functions/types-reference/) or [Python](https://www.palantir.com/docs/foundry/functions/python-getting-started/).
*   **Model development** is supported in Code Repositories. [Learn more about how to develop models in Code Repositories.](https://www.palantir.com/docs/foundry/integrate-models/model-asset-code-repositories/)
