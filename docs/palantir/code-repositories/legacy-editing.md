# [](https://www.palantir.com/docs/foundry/code-repositories/legacy-editing/#python-transforms-in-code-repositories-legacy)Python transforms in Code Repositories [Legacy]

Python transforms support in Code Repositories is in the [legacy](https://www.palantir.com/docs/foundry/platform-overview/development-life-cycle/) phase of development. The Code Repositories editor will remain supported and available, though future feature development will focus on VS Code workspaces. 

[VS Code workspace](https://www.palantir.com/docs/foundry/vs-code/overview/) is the recommended environment for working with Python transforms and includes the current features of Code Repositories along with AI-powered coding assistance, full dataset preview, an optimized language server, and an integrated terminal. 

[Review a feature comparison between VS Code workspaces and Code Repositories.](https://www.palantir.com/docs/foundry/vs-code/overview/#feature-comparison)

[Learn more about the benefits of VS Code workspaces.](https://www.palantir.com/docs/foundry/vs-code/benefits/)

Python transforms support in Code Repositories is in the [legacy](https://www.palantir.com/docs/foundry/platform-overview/development-life-cycle/) phase of development. Workflows for additional repository types [supported in VS Code workspaces](https://www.palantir.com/docs/foundry/vs-code/overview/#supported-workflows) will move to the legacy phase over time.

If VS Code workspaces are unavailable on your enrollment, Code Repositories remains the recommended way to author Python transforms.

## [](https://www.palantir.com/docs/foundry/code-repositories/legacy-editing/#available-transforms-in-code-repositories)Available transforms in Code Repositories

Code Repositories remains the recommended editor for other repository types, including Java and SQL transforms.
