# [](https://www.palantir.com/docs/foundry/action-types/configure-sections/#configure-sections)配置 sections

Action form 可以通过 **sections** 进行自定义。Sections 提供 parameter 的逻辑分组，用于组织 action form。Sections 还支持列、描述和条件覆盖。

![Image 3: form 概览](https://www.palantir.com/docs/resources/foundry/action-types/form-overview.png?width=500)
## [](https://www.palantir.com/docs/foundry/action-types/configure-sections/#adding-a-section-to-an-action-form)向 action form 添加 section

在 Form 标签页中，点击 **Add section**。这会打开一个详细的 section 配置模态框，你可以在其中添加标题、选择列布局，以及可选地编写面向用户的描述。描述不带样式，与 parameter 描述不同，它始终直接显示在 section 本身中，而不是在 tooltip 中。

你可以将 parameter 组织成列，以更高效地利用 form 内的空间，或者将相关 parameter 更紧密地分组。一个 section 可以分为一列或两列。当你使用不需要大量 form 空间的 parameter 时，分列特别有用。

![Image 4: form 内的 section](https://www.palantir.com/docs/resources/foundry/action-types/section-config.png?width=500)
Sections 还可以折叠、完全隐藏，以及使用条件覆盖，提供更多 form 行为自定义方式。所有这些功能也会应用于 section 内的 parameter。组合使用这些功能可以创建更智能的 form，在适当条件下展示所需的 parameter。一个 section 可以先隐藏，然后根据先前的 parameter 值再显示。

## [](https://www.palantir.com/docs/foundry/action-types/configure-sections/#adding-parameters-to-a-section)向 section 添加 parameter

有两种方式向 section 添加 parameter：从 section 配置视图中，或从 **Form** 标签页中。

在 section 配置视图中，点击 **Add new parameter**。然后在该 section 内配置新添加的 parameter。或者点击 **Add existing parameter** 将已有 parameter 移入该 section。

**Form** 标签页以单一概览列出 sections 及其 parameter。点击 parameter 左侧的八个点，将其拖入已有的 section。Parameter 和 section 在 form 中的显示顺序取决于它们在 **Form Content** 区域中的排列顺序。
