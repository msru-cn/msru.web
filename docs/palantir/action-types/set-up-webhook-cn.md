# [](https://www.palantir.com/docs/foundry/action-types/set-up-webhook/#set-up-a-webhook)设置 webhook

## [](https://www.palantir.com/docs/foundry/action-types/set-up-webhook/#prerequisites)前提条件

1.   完成 [快速开始](https://www.palantir.com/docs/foundry/action-types/getting-started/) 教程，了解如何设置基本 action。
2.   设置一个 [webhook](https://www.palantir.com/docs/foundry/data-connection/webhooks-setup/) 以创建与外部系统的连接。你可能需要与有权限连接到源系统的系统管理员合作，然后再创建 webhook。

## [](https://www.palantir.com/docs/foundry/action-types/set-up-webhook/#steps)步骤

在下面的例子中，假设我们有一个名为 **Modify ticket priority** 的 webhook，它接受一个 `priority` 字符串值并将其发送到外部系统。

导航到你的 action，选择 **Logic** 标签页，选择 **Add new rule**，然后选择 **Webhook**。

![Image 7: 添加新 webhook](https://www.palantir.com/docs/resources/foundry/action-types/webhooks-add-new-rule-webhook.png?width=600)
默认情况下，新添加的 webhook 被配置为 **side effect**；这使 webhook 在 Foundry 中 object 被编辑 _之后_ 运行。或者，选择 **Writeback** 使 webhook 在 object 编辑 _之前_ 运行。

![Image 8: 选择 writeback 或 side effect](https://www.palantir.com/docs/resources/foundry/action-types/webhooks-select-writeback-or-side-effect.png?width=400)
在下面的菜单中，选择你要执行的 webhook。在这个例子中，我们选择 **Modify ticket priority** webhook。如果需要，你可以选择 webhook 的不同版本。

![Image 9: 选择要执行的 webhook](https://www.palantir.com/docs/resources/foundry/action-types/webhooks-select-webhook-to-execute.png?width=400)
接下来，基于 action parameters 配置 webhook 输入参数。默认情况下，会为每个 webhook 输入生成一个新的 action parameter，除非已存在同名的 action parameter，在这种情况下会自动配置现有 parameter。在这个例子中，我们将名为 `priority` 的 webhook 输入映射到名为 `Ticket Priority` 的已有 action parameter。

![Image 10: 将 webhook 输入映射到已有 action parameter](https://www.palantir.com/docs/resources/foundry/action-types/webhooks-input-mapping-example.png?width=400)
选择 **Add webhook** 完成将 webhook rule 添加到 action 的操作。注意，webhook 添加后，Rules 区域显示 writeback 将在 object 被修改之前发生。

![Image 11: 添加新 webhook（完成）](https://www.palantir.com/docs/resources/foundry/action-types/webhooks-add-webhook-complete.png?width=600)
你可能想要移除添加 webhook 时创建的现在未使用的自动生成 parameters。

![Image 12: 移除自动生成的 parameters](https://www.palantir.com/docs/resources/foundry/action-types/webhooks-remove-autogenerated-parameters.png?width=600)
在右上角选择 **Save** 保存你对 action 的更改。现在，当 action 被应用时，对外部系统的请求将在对 Foundry 中 object 进行任何更改之前发出。
