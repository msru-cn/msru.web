# [](https://www.palantir.com/docs/foundry/action-types/marketplace-action-types/#add-action-types-to-marketplace-product)将 action types 添加到 Marketplace product

使用 [Foundry DevOps](https://www.palantir.com/docs/foundry/devops/overview/) 将你的 action types 包含在 [Marketplace products](https://www.palantir.com/docs/foundry/devops/core-concepts/#product) 中，供其他用户安装和复用。[了解如何创建你的第一个 product。](https://www.palantir.com/docs/foundry/foundry-devops/create-products/)

## [](https://www.palantir.com/docs/foundry/action-types/marketplace-action-types/#supported-features)支持的功能

大多数 action type 功能都受支持，除了引用了 [具有不支持功能的 object types](https://www.palantir.com/docs/foundry/object-link-types/marketplace-ontology-types/#unsupported-features) 的 action。在准备打包 action type 时，确保你的 action type 的 [**Security & Submission criteria**](https://www.palantir.com/docs/foundry/action-types/getting-started/#add-submission-criteria) 不引用用户；将任何用户引用更改为引用 group。

## [](https://www.palantir.com/docs/foundry/action-types/marketplace-action-types/#adding-action-types-to-products)将 action types 添加到 products

要将 action type 添加到 product，首先 [创建一个 product](https://www.palantir.com/docs/foundry/foundry-devops/create-products/)，然后选择 **Action type** content type，如下所示。

![Image 4: 添加 action type。](https://www.palantir.com/docs/resources/foundry/action-types/marketplace-add-action-type.png)

然后会提示你选择一个 action type。

![Image 5: 添加 action type 对话框。](https://www.palantir.com/docs/resources/foundry/action-types/marketplace-add-action-type-dialog.png)

虽然你可以直接选择 action types，但我们建议先添加 [Workshop applications](https://www.palantir.com/docs/foundry/workshop/marketplace-workshop/) 等内容，然后通过 dependencies panel 选择相关 action，如下所示。

![Image 6: 通过 panel 添加 action type。](https://www.palantir.com/docs/resources/foundry/action-types/marketplace-add-action-type-panel.png)
