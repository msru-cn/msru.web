# [](https://www.palantir.com/docs/foundry/data-integration/source-type-overview/#connectors)Connectors

The [Data Connection](https://www.palantir.com/docs/foundry/data-connection/overview/) application is intended to provide connectivity between Foundry and your systems. This page provides an overview of the available connectors.
