# [](https://www.palantir.com/docs/foundry/aip-analyst/overview/#aip-analyst)AIP Analyst

AIP Analyst 是一个用于 Agent 工作流的界面，让你使用自然语言对 Ontology 执行即席分析。你可以向 AIP Analyst 提问，Agent 会通过自主搜索 Ontology、创建 object sets 和转换数据来回答问题，然后生成摘要和可视化。

## [](https://www.palantir.com/docs/foundry/aip-analyst/overview/#example-workflow)示例工作流

举个例子，假设一个用户经营咖啡连锁店，想进行竞争分析。他想研究在英国 Northampton 开新店是否可行。开始分析时，这个用户可以问"Northampton 10公里范围内有哪些咖啡店？连锁店是否特别多？"

AIP Analyst 使用多个搜索词在 Ontology 中搜索相关数据，以增加找到相关 object type 的可能性。

![Image 4: AIP Analyst 的 object type 搜索。](https://www.palantir.com/docs/resources/foundry/aip-analyst/aip-analyst-workflow-1.png)

找到一些咖啡店后，AIP Analyst 检查数据并应用以 Northampton 为中心的地理空间过滤。

![Image 5: AIP Analyst 地理空间过滤。](https://www.palantir.com/docs/resources/foundry/aip-analyst/aip-analyst-workflow-2.png)

最后，在对连锁店进行一些额外的聚合操作后，生成指定区域内店铺和竞争连锁店的摘要。

![Image 6: AIP Analyst 摘要示例。](https://www.palantir.com/docs/resources/foundry/aip-analyst/aip-analyst-workflow-3.png)

## [](https://www.palantir.com/docs/foundry/aip-analyst/overview/#more-ways-to-use-aip-analyst)更多 AIP Analyst 使用方式

除了运行即席分析，AIP Analyst 还可以：

*   **将分析保存为 Compass 资源：** 稍后回到工作或通过[分析资源](https://www.palantir.com/docs/foundry/aip-analyst/analysis-resources/)与协作者共享。
*   **嵌入到其他应用中：** 添加 [Workshop 组件](https://www.palantir.com/docs/foundry/aip-analyst/workshop-widget/)在 Workshop module 中实现更紧密集成，或使用 [URL 参数](https://www.palantir.com/docs/foundry/aip-analyst/embed/)在 OSDK 或其他 Foundry 应用中进行 iframe 嵌入。

注意：AIP 功能可用性可能会变化，不同客户之间可能有所不同。
