# [](https://www.palantir.com/docs/foundry/authentication/multi-factor-auth/#multi-factor-authentication)MFA 多因素认证

访问 Foundry 需要 _MFA 多因素认证_，可以在 Foundry 中使用基于应用的双因素认证，或直接通过 IdP 完成。[了解更多关于 Palantir 身份安全建议。](https://www.palantir.com/docs/foundry/security/protect-foundry-installation/#identity-security)

配置 SAML 2.0 集成后，点击页面顶部的返回箭头，展开 **Multi-factor authentication** 部分，为你的用户选择多因素认证方式。

![Image 3: MFA](https://www.palantir.com/docs/resources/foundry/authentication/mfa.png)

设置好 MFA 后，[继续配置组织分配](https://www.palantir.com/docs/foundry/authentication/org-assignment/)。

如果你无法生成 MFA 验证码，或者组织中有用户需要重置 MFA，先联系组织的 IT 团队了解 MFA 的管理方式。

**如果 MFA 由组织 IT 通过 IdP 管理** 你的 IT 团队需要处理任何重置请求。

**如果 MFA 在 Foundry 中管理** 组织中的 Foundry 平台管理员可以通过以下步骤重置双因素认证/MFA：

1.   在 Foundry 中，从浏览器左下角进入 **Account > Settings**。
2.   在 **Platform Settings** 下，选择 **Users**。
3.   搜索目标用户，从列表中选择其姓名。
4.   侧边栏会显示 **Reset two-factor auth method...** 选项，点击它。
5.   在确认界面中，确认你要完成重置。
6.   确认后，你会收到成功提示，用户也会收到关于重置 MFA 后续步骤的通知。

![Image 4: reset_MFA](https://www.palantir.com/docs/resources/foundry/authentication/reset_mfa.png)
