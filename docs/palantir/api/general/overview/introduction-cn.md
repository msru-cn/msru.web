# 简介

Foundry API 是一个开发者友好的 REST API，用于与 Palantir 的 Foundry 平台交互。可以用来在 Palantir 产品之上构建应用。

Foundry API 是一个表述性状态转移（REST）API，由 HTTP 端点组成。端点使用 OAuth 2.0 协议进行认证，采用通用设计模式，主要使用 JSON 格式的请求和响应。

**参见 [Getting started page](https://www.palantir.com/docs/foundry/api/general/overview/getting-started/) 开始使用 API。**

需要从 Foundry 导出数据？[Data connection exports](https://www.palantir.com/docs/foundry/data-connection/export-overview/) 可能更适合你的场景。
