# [](https://www.palantir.com/docs/foundry/administration/overview/#management-and-enablement)管理与启用

Palantir 平台提供完整的治理和管理功能套件，可通过称为 **Control Panel** 的集中式界面访问。平台将安全、资源管理、用例生命周期和审计功能整合到一个共享基础中，可以在各种实施中一致应用。除核心治理外，这还实现了企业数据架构的规模化实施，包括"数据网格"和"数据编织"范式。无论是集中式还是联邦式模型，Palantir 的管理、管理和启用方法都能消除安全与丰富协作之间的传统妥协。

## [](https://www.palantir.com/docs/foundry/administration/overview/#control-panel)Control Panel

所有管理工作流都可以在 [Control Panel](https://www.palantir.com/docs/foundry/administration/control-panel/)（Palantir 管理平台的集中式界面）中执行。你可以通过 [Workspace 侧边栏](https://www.palantir.com/docs/foundry/getting-started/orientation-and-nav/#workspace-navigation-sidebar) 选择 **Open other workspaces** 来访问 Control Panel。

## [](https://www.palantir.com/docs/foundry/administration/overview/#configure-and-manage-enrollments)配置和管理 enrollments

Palantir enrollments 定义为由平台管理员管理的一个或多个"[Organizations](https://www.palantir.com/docs/foundry/security/orgs-and-spaces/#organizations)"。每个管理功能可以映射到现有的治理实施（如 Active Directory），在预先存在的组和特定角色之间进行细粒度映射。全部管理任务可以通过 Control Panel 定义、联合和实施。

[了解有关管理 enrollments 的更多信息。](https://www.palantir.com/docs/foundry/administration/enrollments-and-organizations/)

## [](https://www.palantir.com/docs/foundry/administration/overview/#authentication)认证

对 Palantir 平台的访问通过注册的身份提供商管理，它们提供用户验证和驱动整个平台[安全控制](https://www.palantir.com/docs/foundry/platform-security-management/manage-users/)所需的自主属性。Palantir 利用 SAML 2.0 开放标准，并提供直观的机制将元数据属性映射到平台内管理的用户属性。随着 Palantir 平台在 Organization 内的使用扩展，并可能增长到包含外部合作伙伴 Organizations，可以引入和管理额外的身份提供商。

[了解有关认证的更多信息。](https://www.palantir.com/docs/foundry/authentication/overview/)

## [](https://www.palantir.com/docs/foundry/administration/overview/#resource-management)资源管理

Palantir 为管理员提供全面的资源管理工具，使他们能够了解和管理平台资源的利用情况。这组功能确保可操作、细粒度的指标可以追溯回语义上有意义的账户、Projects 甚至单个资源。使用可见性工作流为面向 Project 的资源支出提供了丰富的视角，而资源分配工作流允许管理员定义 Projects 如何消耗共享资源——如果需要，还可以限制消耗。

[了解有关资源管理的更多信息。](https://www.palantir.com/docs/foundry/resource-management/overview/)

## [](https://www.palantir.com/docs/foundry/administration/overview/#platform-experience)平台体验

Palantir 提供一系列配置选项，旨在实现组织一致性和用户体验的聚焦。这包括[可配置的 workspaces](https://www.palantir.com/docs/foundry/carbon/overview/)，将平台应用总集策划为适合特定团队或用户类型需求的子集。用户着陆页、平台 logo 和其他资产也可以自定义，确保 Palantir 平台与更广泛组织的外观和品牌原生集成。

了解有关自定义平台体验的更多信息：

*   [配置平台体验设置](https://www.palantir.com/docs/foundry/administration/configure-platform-experience/)
*   [配置 workspaces](https://www.palantir.com/docs/foundry/administration/configure-workspaces/)
