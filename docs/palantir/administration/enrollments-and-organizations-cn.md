# [](https://www.palantir.com/docs/foundry/administration/enrollments-and-organizations/#enrollments-and-organizations)Enrollments 和 Organizations

_Organizations_ 是应用于 _Projects_ 的访问要求，在用户和资源组之间强制执行严格的隔离。每个用户只是一个 Organization 的成员，但可以是多个 Organization 的访客成员。[了解有关 Organizations 的更多信息](https://www.palantir.com/docs/foundry/security/orgs-and-spaces/#organizations)。

**Enrollment** 代表 Foundry 平台的一个实例，由一个或多个 Organizations 组成。大多数情况下，一个公司在其 enrollment 中只有一个 Organization（包含所有用户）。一些 enrollment 有多个 Organizations 以在用户组之间强制执行严格隔离，例如多家公司在同一 Foundry 平台上协作时。

Control Panel 中的大多数设置在 Organization 级别管理，以实现配置的细粒度和管理委派，但有些是 enrollment 全局的，如 [Resource Management](https://www.palantir.com/docs/foundry/resource-management/overview/)。
