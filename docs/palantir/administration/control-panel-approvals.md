# [](https://www.palantir.com/docs/foundry/administration/control-panel-approvals/#approvals-in-control-panel)Approvals in Control Panel

Control Panel features a dedicated [Approvals](https://www.palantir.com/docs/foundry/approvals/overview/) integration designed to facilitate the process of requesting, approving, and maintaining a history of sensitive workflows within Control Panel.

## [](https://www.palantir.com/docs/foundry/administration/control-panel-approvals/#approvals-inbox)Approvals inbox

All approvals appear in Control Panel's approvals inbox. To access, select on the **Approvals** tab at the very top of Control Panel's sidebar.

![Image 2: The Control Panel Approvals inbox interface shows current approval requests.](https://www.palantir.com/docs/resources/foundry/administration/control-panel-approvals-inbox.png)

## [](https://www.palantir.com/docs/foundry/administration/control-panel-approvals/#supported-workflows)Supported workflows

Control Panel's integration with Approvals is under active development. Current supported workflows include:

*   [Configuring network ingress](https://www.palantir.com/docs/foundry/administration/configure-ingress/)
*   [Configuring network egress](https://www.palantir.com/docs/foundry/administration/configure-egress/)
*   [Configuring Ontology SDK web hosting](https://www.palantir.com/docs/foundry/developer-console/deploy-custom-application-on-foundry/)
