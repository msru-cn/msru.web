# [](https://www.palantir.com/docs/foundry/administration/control-panel/#control-panel)Control Panel

所有管理工作流都可以在 **Control Panel**（Foundry 管理平台的中集中式界面）中执行。你可以从 Applications Portal 访问 Control Panel。

![Image 3: 从 Applications Portal 视图查看 Control Panel 应用。](https://www.palantir.com/docs/resources/foundry/administration/control-panel-application-portal.png)

Control Panel 主页提供你的 enrollment 和组织的概览，以及执行常见管理工作流的链接。

![Image 4: Control Panel 主页](https://www.palantir.com/docs/resources/foundry/administration/control-panel-homepage.png)

Control Panel 中的其他设置以侧面板上的标签页呈现，按 enrollment/Organization 级别分组。要搜索特定设置，通过选择侧面板中的 **Search** 或使用 `Cmd+J`（macOS）或 `Ctrl+J`（Windows）打开搜索对话框。
