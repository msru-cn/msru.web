# [](https://www.palantir.com/docs/foundry/administration/platform-communications/#configure-contact-information)配置联系信息

可以在 Control Panel 的 **Contact information** 部分配置与 Foundry 运营和管理相关的通信收件人。

![Image 2: 联系信息配置渠道](https://www.palantir.com/docs/resources/foundry/administration/control-panel-contact-information.png)

有四个渠道允许将相关通信的子集路由到不同的收件箱。一个常见的最佳实践是订阅邮件列表而非个人账户，以确保不会错过关键通信。注意，至少需要一个电子邮件地址注册以接收 **Platform administration** 消息。

四个通信路由渠道是：

*   **Platform administration：** 关于平台管理的高度重要消息，包括即将到来的产品生命周期过渡、AIP 试用到期和续期信息，以及平台管理员需要采取的操作。（注意：如果以下"Security"、"Service disruption"和"Legal and privacy"类别留空，则来自这些类别的消息将发送到此地址。）
*   **Security updates：** 安全相关通信，包括 CVE 披露或可疑活动检测。
*   **Service disruption announcements：** 关于计划维护窗口的通知，以及平台组件出现中断或性能下降时的警报和更新。
*   **Legal and privacy：** 关于平台使用条款和条件、数据保护计划以及其他合同或监管通信的通知。

这些通信渠道面向 Foundry 管理员和项目团队成员。面向用户和开发者的通信（如产品和功能公告）在平台文档的 [Announcements](https://www.palantir.com/docs/foundry/announcements/) 部分提供。

对于需要用户关注的[平台变更](https://www.palantir.com/docs/foundry/upgrade-assistant/platform-changes/)，[Upgrade Assistant](https://www.palantir.com/docs/foundry/upgrade-assistant/overview/) 负责跟踪受影响的资源并联系负责人。
