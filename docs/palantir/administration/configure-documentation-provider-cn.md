# [](https://www.palantir.com/docs/foundry/administration/configure-documentation-provider/#configure-documentation-provider)配置文档提供商

要配置 Foundry 如何向用户提供平台文档，请打开 Control Panel 并导航到 **Enrollment Settings > Support > Documentation**。所选设置将应用于此 enrollment 内组织的所有用户。更改可能需要最多 10 分钟才能同步到所有用户。

你可以选择以下文档提供商选项：

*   [公共文档网站](https://www.palantir.com/docs/foundry/administration/configure-documentation-provider/#public-documentation-website)
*   [平台内镜像](https://www.palantir.com/docs/foundry/administration/configure-documentation-provider/#in-platform-mirror)

### [](https://www.palantir.com/docs/foundry/administration/configure-documentation-provider/#public-documentation-website)公共文档网站

如果选择公共文档网站作为文档提供商，导航到 `${YOUR_WORKSPACE_URL}/docs` 的用户将被自动重定向到 `palantir.com/docs` 公共网站。如果导航到特定文档页面，用户将被重定向到公共网站上的对应页面。

这是大多数客户的推荐设置，因为文档更新通常先在公共网站上提供，然后才同步到平台内镜像。

如果用户在使用 Palantir 平台时预计无法访问互联网，请考虑使用平台内镜像配置选项。

### [](https://www.palantir.com/docs/foundry/administration/configure-documentation-provider/#in-platform-mirror)平台内镜像

如果选择平台内镜像选项，导航到 `${YOUR_WORKSPACE_URL}/docs` 的用户将看到从公共文档网站的平台内镜像提供的文档内容。这适用于用户在使用 Palantir 平台时预计无法访问互联网的情况。

此选项可能并非所有客户都可用。如果你对此选项感兴趣但似乎不可用，请联系你的 Palantir 代表。
