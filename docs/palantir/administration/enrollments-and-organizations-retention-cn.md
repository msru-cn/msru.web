# [](https://www.palantir.com/docs/foundry/administration/enrollments-and-organizations-retention/#retention-policies)保留策略

**Data retention** 是整体存储管理系统的一部分，描述了管控数据在 Palantir 平台中存储时长和如何移除数据的过程。与 FIPPs 一致，敏感数据（特别是 PII）通常必须在处理目的达成后尽快删除，以遵守适用的数据保护法规。根据你的合同协议或合规需求，某些数据也可能需要保留。因此你应注意，从 Palantir 平台删除在某个时间点将变得不可逆，并在整个过程中实施相关控制，如资格审查。

我们强烈建议你尽早确定保留需求，理想情况下在任何数据被摄取之前。

更多信息请参阅[保留机制如何工作](https://www.palantir.com/docs/foundry/retention/overview/)的文档，或联系 Palantir Support。
