# [](https://www.palantir.com/docs/foundry/administration/control-panel-approvals/#approvals-in-control-panel)Control Panel 中的 Approvals

Control Panel 集成了专门的 [Approvals](https://www.palantir.com/docs/foundry/approvals/overview/) 功能，旨在促进 Control Panel 内敏感工作流的请求、审批和历史记录维护过程。

## [](https://www.palantir.com/docs/foundry/administration/control-panel-approvals/#approvals-inbox)Approvals 收件箱

所有审批都出现在 Control Panel 的 approvals 收件箱中。要访问，选择 Control Panel 侧边栏最顶部的 **Approvals** 标签页。

![Image 2: Control Panel Approvals 收件箱界面显示当前的审批请求。](https://www.palantir.com/docs/resources/foundry/administration/control-panel-approvals-inbox.png)

## [](https://www.palantir.com/docs/foundry/administration/control-panel-approvals/#supported-workflows)支持的工作流

Control Panel 与 Approvals 的集成正在积极开发中。当前支持的工作流包括：

*   [配置网络 ingress](https://www.palantir.com/docs/foundry/administration/configure-ingress/)
*   [配置网络 egress](https://www.palantir.com/docs/foundry/administration/configure-egress/)
*   [配置 Ontology SDK web 托管](https://www.palantir.com/docs/foundry/developer-console/deploy-custom-application-on-foundry/)
