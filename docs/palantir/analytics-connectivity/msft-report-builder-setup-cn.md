# [](https://www.palantir.com/docs/foundry/analytics-connectivity/msft-report-builder-setup/#setup)设置

现在可以在 Report Builder 中访问 Palantir Foundry 数据集，用于构建报告和可视化。要在 Report Builder 中使用 Foundry，需要先在本地电脑安装 Foundry ODBC 驱动。按以下指南完成安装。

### [](https://www.palantir.com/docs/foundry/analytics-connectivity/msft-report-builder-setup/#step-1-install-the-odbc-driver)第一步：安装 ODBC 驱动

首先安装 ODBC 驱动。前往[下载页面：ODBC 驱动](https://www.palantir.com/docs/foundry/analytics-connectivity/downloads/#foundry-datasets-odbc-driver)下载安装。

安装遇到问题请联系 Palantir 代表。

### [](https://www.palantir.com/docs/foundry/analytics-connectivity/msft-report-builder-setup/#step-2-get-started-building-reports)第二步：开始构建报告

ODBC 驱动安装完成后，按照 [Microsoft Report Builder：入门指南](https://www.palantir.com/docs/foundry/analytics-connectivity/msft-report-builder-getting-started/)开始构建基于 Foundry 数据的第一个报告。
