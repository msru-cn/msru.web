# [](https://www.palantir.com/docs/foundry/analytics-connectivity/overview/#connectivity-sql--bi)连接：SQL & BI

Foundry 的开放架构让数据和转换逻辑都能以非专有格式访问。通过以开放格式存储数据、暴露 API、支持便捷的数据连接和导出，以及提供转换代码访问，Foundry 可以轻松与第三方软件和开源工具互操作。

Foundry 的开放集成生态可以通过安装自定义连接器进一步扩展，支持与 Power BI® 和 Tableau 等主流商业智能软件的特定集成。Foundry 还提供 ODBC 和 JDBC 驱动，可用于连接更多第三方工具。

使用本指南设置 Foundry 商业智能工具集成、通过 Foundry 认证，并在第三方工具中使用 Foundry 数据。
