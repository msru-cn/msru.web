# [](https://www.palantir.com/docs/foundry/analytics-connectivity/tableau-overview/#tableau)Tableau

The Foundry integration for Tableau offers the following:

*   Enables you to easily create Tableau interactive dashboards backed by Foundry data.
*   Supports both [Extracts and Live Connections.](https://www.tableau.com/about/blog/2016/4/tableau-online-tips-extracts-live-connections-cloud-data-53351)
*   Compatible with Foundry access controls, including granular permissions.

## [](https://www.palantir.com/docs/foundry/analytics-connectivity/tableau-overview/#supported-tableau-products)Supported Tableau products

*   _Tableau Desktop_ (2019.4 release or later)
*   _Tableau Server_ (2019.4 release or later)

Note that _Tableau Online via Tableau Bridge_ is not currently supported by the Tableau custom connector. We anticipate that support for the connector will become available with future releases of Tableau.
