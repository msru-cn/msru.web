# [](https://www.palantir.com/docs/foundry/analytics-connectivity/identify-dataset-rid/#identify-a-datasets-rid-or-filepath)识别数据集的 RID 或文件路径

在第三方 BI 工具中使用 Foundry 数据时，需要指定要使用的数据集。有些工具提供图形界面来浏览和选择数据集，有些则需要直接输入数据集信息。

Foundry 提供两种指定数据集的方式：

*   "RID"：数据集标识符
*   "Location"：数据集的文件路径

在 Foundry 中找到这些值：进入数据集的"About"页面，点击"see more"，然后从左侧边栏复制"RID"值或"Location"。
