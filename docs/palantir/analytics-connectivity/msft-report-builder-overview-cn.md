# [](https://www.palantir.com/docs/foundry/analytics-connectivity/msft-report-builder-overview/#microsoft-report-builder)Microsoft Report Builder

Foundry 与 Microsoft Report Builder 的集成提供以下能力：

*   在 Report Builder 中轻松创建基于 Foundry 数据的报告。
*   兼容 Foundry 访问控制，包括桌面版的细粒度权限。
*   桌面版支持基于 token 的认证。

## [](https://www.palantir.com/docs/foundry/analytics-connectivity/msft-report-builder-overview/#supported-report-builder-products)支持的 Report Builder 产品

*   _Report Builder Desktop_（2020 年 9 月版本或更高）
