### [](https://www.palantir.com/docs/foundry/analytics-connectivity/downloads/#foundry-datasets-odbc-driver)Foundry 数据集 ODBC 驱动

安装驱动：下载下方的 Palantir 签名安装程序，按屏幕提示操作。配置到 Foundry 的连接请参考 [ODBC 设置指南](https://www.palantir.com/docs/foundry/analytics-connectivity/odbc-jdbc-drivers/#odbc-1)。

支持 Windows 64 位。暂不支持 Windows 32 位、Mac 和 Linux。

下载：

*   [Foundry ODBC Driver 3.39.0 (Windows x64) ↗](https://www.palantir.com/drivers/artifacts/datasets/odbc/3.39.0/foundry-sql-odbc-driver-3.39.0.exe)

### [](https://www.palantir.com/docs/foundry/analytics-connectivity/downloads/#foundry-datasets-jdbc-driver)Foundry 数据集 JDBC 驱动

安装驱动：下载下方的 .jar 文件，按应用文档说明放到本机相应目录。配置到 Foundry 的连接请参考 [JDBC 设置指南](https://www.palantir.com/docs/foundry/analytics-connectivity/odbc-jdbc-drivers/#jdbc-1)。

需要 Java 11+。

下载：

*   [Foundry JDBC Driver 3.39.0 (JRE 11+) ↗](https://www.palantir.com/drivers/artifacts/datasets/jdbc/3.39.0/foundry-sql-jdbc-driver-3.39.0-withdep.jar)

### [](https://www.palantir.com/docs/foundry/analytics-connectivity/downloads/#foundry-datasets-tableau-connector-20211)Foundry 数据集 Tableau 连接器（2021.1+）

Foundry 数据集 Tableau 连接器是 Palantir 签名的 Tableau 连接器，以 .taco 包文件形式提供。

连接器也可在 [Tableau Exchange ↗](https://exchange.tableau.com/products/628) 获取。Tableau Exchange 版本与下方链接版本完全一致。

下载：

*   [foundry-jdbc-2.6.0.taco ↗](https://www.palantir.com/drivers/artifacts/datasets/tableau/2.6.0/foundry-jdbc-2.6.0.taco)

### [](https://www.palantir.com/docs/foundry/analytics-connectivity/downloads/#foundry-datasets-tableau-connector)Foundry 数据集 Tableau 连接器（旧版）

如果你的 Tableau 版本在 `2019.4` 到 `2021.1` 之间，请使用此版本。功能与上方版本相同，但仅支持 token 认证（不支持 OAuth），且数据集必须通过 RID/路径加载，不能搜索。

下载：

*   [foundry-jdbc-1.2.0.taco ↗](https://www.palantir.com/drivers/artifacts/datasets/tableau/1.2.0/foundry-jdbc-1.2.0.taco)
