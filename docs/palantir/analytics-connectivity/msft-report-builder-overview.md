# [](https://www.palantir.com/docs/foundry/analytics-connectivity/msft-report-builder-overview/#microsoft-report-builder)Microsoft Report Builder

The Foundry integration for Microsoft Report Builder offers the following:

*   Enables you to easily create reports in Report Builder backed by Foundry data.
*   Offers compatibility with Foundry access controls, including granular permissions, for Desktop.
*   Supports token-based authentication for Desktop.

## [](https://www.palantir.com/docs/foundry/analytics-connectivity/msft-report-builder-overview/#supported-report-builder-products)Supported Report Builder products

*   _Report Builder Desktop_ (September 2020 release or later)
