# [](https://www.palantir.com/docs/foundry/analytics-connectivity/power-bi-overview/#power-bi)Power BI®

本页讨论 Power BI® 连接器的实现，用于从 Power Query 界面访问 Foundry 资源。如果你在找 Microsoft Power BI® XMLA 连接器的数据集成信息，请参阅我们的[数据连接文档](https://www.palantir.com/docs/foundry/available-connectors/microsoft-power-bi-xmla/)。

## [](https://www.palantir.com/docs/foundry/analytics-connectivity/power-bi-overview/#what-is-the-foundry-integration-for-power-bi)Foundry Power BI® 集成是什么？

*   包含 Microsoft 认证的 Power Query 连接器，轻松创建基于 Foundry 数据的 Power BI® 报告。
*   支持 [Import 和 DirectQuery](https://docs.microsoft.com/en-us/power-bi/connect-data/desktop-use-directquery) 两种模式。
*   兼容 Foundry 访问控制，包括 Power BI® Desktop 的细粒度权限。
*   Power BI® Desktop 支持 OAuth 认证和基于 token 的认证。

## [](https://www.palantir.com/docs/foundry/analytics-connectivity/power-bi-overview/#supported-power-bi-products)支持的 Power BI® 产品

*   **Power BI® Desktop**（2020 年 6 月版本或更高）
*   **Power BI® Service via Power BI® Gateway**（2020 年 6 月版本或更高）

_注意：Power BI® 自定义连接器目前不支持 **Power BI® Report Server**。但可以使用标准 [ODBC 驱动](https://www.palantir.com/docs/foundry/analytics-connectivity/odbc-jdbc-drivers/)连接。_

## [](https://www.palantir.com/docs/foundry/analytics-connectivity/power-bi-overview/#power-query-compatibility)Power Query 兼容性

作为认证的 Power Query 连接器，该集成让 Foundry 数据可在多种 Microsoft 产品中访问：

*   Microsoft Fabric（Dataflow Gen2）
*   Power Platform（包括 Dataverse 和 Power Apps）
*   Power BI®（Dataflows 和语义模型）

了解更多兼容性信息，请参阅 [Microsoft Power Query 文档中的 Palantir Foundry 页面 ↗](https://learn.microsoft.com/en-us/power-query/connectors/palantir-foundry-datasets)。
