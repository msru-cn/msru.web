# [](https://www.palantir.com/docs/foundry/foundry-devops/supported-resources/#supported-resources)Supported resources

The vast majority of Foundry resource types can be included as outputs when [creating a product](https://www.palantir.com/docs/foundry/foundry-devops/create-products/).

For packaging constraints and details specific to each resource type, refer to the resource's Marketplace documentation. For example, see the Marketplace documentation for [Action types](https://www.palantir.com/docs/foundry/action-types/marketplace-action-types/) or [Automations](https://www.palantir.com/docs/foundry/automate/marketplace-automate/).

## [](https://www.palantir.com/docs/foundry/foundry-devops/supported-resources/#unsupported-resources)Unsupported resources

If a resource is unsupported, the resource will show in the draft with an error. Unsupported resources must be removed from the draft before publishing. All unsupported resources can be removed by using the **Actions** dropdown and selecting **Drop all failed to package**.

![Image 2: The Resources page displays Unsupported Resources.](https://www.palantir.com/docs/resources/foundry/foundry-devops/unsupported-resource.png)

A non-exhaustive list of unsupported resources is below:

*   [Data Connection sources](https://www.palantir.com/docs/foundry/data-connection/core-concepts/#sources)
*   [Code Workbook workbooks](https://www.palantir.com/docs/foundry/code-workbook/core-concepts/#workbooks)
*   [Fusion sheets](https://www.palantir.com/docs/foundry/fusion/sheets-overview/)
