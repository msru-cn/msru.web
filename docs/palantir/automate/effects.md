# [](https://www.palantir.com/docs/foundry/automate/effects/#effects)Effects

Effects define what happens when an automation is triggered. When a condition is met, the automation executes one or more effects to perform actions, apply logic, execute functions, or send notifications.

## [](https://www.palantir.com/docs/foundry/automate/effects/#effect-types)Effect types

Automate supports the following types of effects:

*   **[Action effects:](https://www.palantir.com/docs/foundry/automate/effect-actions/)** Execute actions on objects, such as creating, modifying, or deleting object instances.
*   **[Logic effects:](https://www.palantir.com/docs/foundry/automate/effect-logic/)** Execute AIP Logic functions.
*   **[Function effects:](https://www.palantir.com/docs/foundry/automate/effect-function/)** Execute a function when the automation condition is met.
*   **[Notification effects:](https://www.palantir.com/docs/foundry/automate/effect-notification/)** Send notifications to users or groups when the automation triggers.

## [](https://www.palantir.com/docs/foundry/automate/effects/#fallback-effects)Fallback effects

Action, logic, and function effects can be configured with a [fallback effect](https://www.palantir.com/docs/foundry/automate/effect-fallback/). Fallback effects execute when the primary effect fails, allowing you to handle errors gracefully by sending notifications, logging failures, or triggering alternative workflows.

## [](https://www.palantir.com/docs/foundry/automate/effects/#effect-settings)Effect settings

Configure how effects execute with [effect settings](https://www.palantir.com/docs/foundry/automate/effect-settings/), including:

*   **Concurrency:** Run effects sequentially or in parallel
*   **Object edits:** Control how multiple edits are handled
*   **Execution guarantees:** Understand at-least-once execution semantics
