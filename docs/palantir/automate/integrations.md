# [](https://www.palantir.com/docs/foundry/automate/integrations/#integrations)Integrations

Automate integrates natively with the following Foundry applications:

*   [AIP Logic](https://www.palantir.com/docs/foundry/automate/integrations/#aip-logic)
*   [Notepad](https://www.palantir.com/docs/foundry/automate/integrations/#notepad)
*   [Object Explorer](https://www.palantir.com/docs/foundry/automate/integrations/#object-explorer)
*   [Ontology Manager](https://www.palantir.com/docs/foundry/automate/integrations/#ontology-manager)
*   [Time series (Quiver)](https://www.palantir.com/docs/foundry/automate/integrations/#time-series-quiver)

## [](https://www.palantir.com/docs/foundry/automate/integrations/#aip-logic)AIP Logic

Automate your AIP Logic to automatically apply or stage Ontology edits for human review. Automations can trigger on existing objects or when new objects are created.

[Learn how to automate your Logic function](https://www.palantir.com/docs/foundry/logic/aip-logic-integration-automate/).

## [](https://www.palantir.com/docs/foundry/automate/integrations/#notepad)Notepad

[Notepad](https://www.palantir.com/docs/foundry/notepad/overview/) documents and [Notepad templates](https://www.palantir.com/docs/foundry/notepad/templates-overview/) can be attached to an automation [notification effect](https://www.palantir.com/docs/foundry/automate/effect-notification/), enabling automated distribution of reports and digests with the latest data from Notepad.

To create an automation directly from Notepad, select the **Actions** dropdown menu in the top right and choose **Add automation**.

![Image 8: Notepad add automation](https://www.palantir.com/docs/resources/foundry/automate/integrations-notepad-add-automation.png)

You will be directed to the automation overview page for the Notepad document. Select **New automation** to launch the automation creation wizard, which will open with the Notepad document pre-filled as an attachment.

![Image 9: Notepad automation overview empty](https://www.palantir.com/docs/resources/foundry/automate/integrations-notepad-automation-overview-empty.png)

After configuring and saving your automation, you will return to the automation overview page within your document, which now displays your newly created automation.

## [](https://www.palantir.com/docs/foundry/automate/integrations/#object-explorer)Object Explorer

Create automations in [Object Explorer](https://www.palantir.com/docs/foundry/object-explorer/overview/) by following the steps below:

1.   Choose **Save** in the exploration view.
2.   Select a Project or folder destination. 

![Image 10: Tooltip showing the save button in Object Explorer.](https://www.palantir.com/docs/resources/foundry/automate/save-exploration-tooltip.png?width=400)

3. After saving, select **Monitor** in the top right of the page to view all automations using this exploration as input. Newly created explorations will show an empty list. 

![Image 11: Empty state view showing the option to add a new automation from an exploration.](https://www.palantir.com/docs/resources/foundry/automate/object-explorer-add-new-automation-zero-state.png?width=400)

 4. Select **Add new automation** to open a simplified setup view for creating a new automation.

![Image 12: create_new_monitor_object_explorer_view](https://www.palantir.com/docs/resources/foundry/automate/object-explorer-create-new-automation.png?width=400)
## [](https://www.palantir.com/docs/foundry/automate/integrations/#ontology-manager)Ontology Manager

[Ontology Manager](https://www.palantir.com/docs/foundry/ontology-manager/overview/) enables users to define their Foundry Ontology, including object types and action types. Automate integrates with Ontology Manager in two ways:

1.   The **Automations** tab in the [object type view](https://www.palantir.com/docs/foundry/ontology-manager/overview/#object-type-view) displays all automations associated with the selected object type, including which automations trigger when objects of that type are created or updated. Select **Add automation** to launch the automation creation wizard with the object type pre-filled as a condition. 

![Image 13: Automation integrations for object types in Ontology Manager.](https://www.palantir.com/docs/resources/foundry/automate/integrations-om-object-type-view.png)

2.   Similarly, the **Automations** tab in the [action type view](https://www.palantir.com/docs/foundry/ontology-manager/overview/#action-type-view) displays all automations that use the selected action type in their [actions effect](https://www.palantir.com/docs/foundry/automate/effect-actions/). Select **Add automation** to launch the creation wizard with the action type pre-filled as an effect.

![Image 14: Automation integrations for action types in Ontology Manager.](https://www.palantir.com/docs/resources/foundry/automate/integrations-om-action-type-view.png)

## [](https://www.palantir.com/docs/foundry/automate/integrations/#time-series-quiver)Time series (Quiver)

You can automate your time series search logic in Quiver so that periods of interest in your time series data can be saved as events in the Ontology.

[Learn how to automate your time series search](https://www.palantir.com/docs/foundry/time-series/alerting-overview/).
