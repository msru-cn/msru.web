# [](https://www.palantir.com/docs/foundry/automate/getting-started/#getting-started-with-automate)Getting started with Automate

This tutorial assumes you already have data integrated into your Foundry Ontology. If you have not yet done this, learn how to [create your Ontology](https://www.palantir.com/docs/foundry/ontology/overview/).

This tutorial will walk you through creating your first simple automation with the Automate application.

## [](https://www.palantir.com/docs/foundry/automate/getting-started/#create-from-the-automate-application)Create from the Automate application

Start by opening the Automate application from the application sidebar. This will take you to the **Overview** page of the Automate application.

The **Overview** page shows a list of your recent automation activity, including counts of total automations you can see, automations owned by you, automations of which you are a recipient, and paused automations. You can also see lists of recently viewed automations, failures within the last four weeks, and recently triggered automations.

![Image 9: The Overview page for the Automate application.](https://www.palantir.com/docs/resources/foundry/automate/automate-overview-page.png)

To create your first automation, select **+ New automation** in the top right of the page. Alternatively, you can:

*   Hover over the Automate application icon in the Foundry sidebar and select **+ New automation**; or
*   Select **+ New** from within a Compass folder and select **Automation**.

![Image 10: Create a new automation from the application sidebar or from within a Compass folder.](https://www.palantir.com/docs/resources/foundry/automate/getting-started-automate-create-automation.png)

You will be taken to the automation creation wizard (shown below) where you can start to define your automation conditions. In this example, you will add a simple **Time** condition.

![Image 11: Add a condition to a new automation.](https://www.palantir.com/docs/resources/foundry/automate/getting-started-add-condition.png)

For now, leave the time configuration page as is and continue on to the **Effect** page by selecting **Next** as shown in the image below.

![Image 12: Configuring a time condition for a new automation.](https://www.palantir.com/docs/resources/foundry/automate/getting-started-time-condition.png)

From the **Effect** page, you can add one or more effects to execute when the time condition is met. Choose **Add** on the **Notification** card to proceed to the **Notification** effect configuration page.

![Image 13: The Effect page for a new automation.](https://www.palantir.com/docs/resources/foundry/automate/getting-started-add-effects.png)

The [notification effect](https://www.palantir.com/docs/foundry/automate/effect-notification/) offers many configuration options. For now, add yourself as a static recipient in the **Recipients** text input. Define a heading and message for your notification, then choose **Preview** to view how the message will appear to recipients. Select **Next** to return to the **Effect** page.

![Image 14: Configure a notification effect and view the message preview.](https://www.palantir.com/docs/resources/foundry/automate/getting-started-notification-effect.png)

You can choose to add additional effects to your notification, but for this example you will continue to the automation **Summary** page by selecting **Next** again.

The **Summary** page shows a condensed view of the conditions and effects configured for your automation. Select **Create automation** to add a file name, save location, and expiration date (**Indefinitely**, **Immediately**, or **Until** a certain date), and [permissions for the automation](https://www.palantir.com/docs/foundry/automate/permissions/).

Upon successful creation, you will be redirected to the detail screen of your newly created automation, where a success banner will be displayed.

Select the Automate icon in the top toolbar to return to the Automate overview page. The **Recent activities** section will populate with events once your automations trigger.

![Image 15: A newly created automation displaying a success banner.](https://www.palantir.com/docs/resources/foundry/automate/getting-started-created-automation-success.png)

To inspect your newly created automation, navigate to the **Automations** tab to view the table of all automations visible with your current permissions. Use the filter pane on the left to search for specific automations, such as the one you just created.

![Image 16: The table of viewable automations, filtered by active automations.](https://www.palantir.com/docs/resources/foundry/automate/getting-started-automations-table-filtered.png)

For more information about configuration options, review the various conditions and effects documentation. Alternatively, explore the [examples section](https://www.palantir.com/docs/foundry/automate/example-weekly-report/) for more complex Automate use cases.
