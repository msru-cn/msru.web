# [](https://www.palantir.com/docs/foundry/automate/marketplace-automate/#add-automations-to-a-marketplace-product)Add automations to a Marketplace product

Use [Foundry DevOps](https://www.palantir.com/docs/foundry/devops/overview/) to include your automations in [Marketplace products](https://www.palantir.com/docs/foundry/devops/core-concepts/#product) for other users to install and reuse. [Learn how to create your first product.](https://www.palantir.com/docs/foundry/foundry-devops/create-products/)

The following Automation features are not supported by Marketplace products:

*   Automations using [saved object sets](https://www.palantir.com/docs/foundry/object-explorer/save-explorations/).
*   Automations with recipients that are not groups.

Automations that use an [action](https://www.palantir.com/docs/foundry/automate/effect-actions/) or [AIP Logic](https://www.palantir.com/docs/foundry/automate/effect-logic/) effect cannot be installed in "production" mode as automations with these effects do not automatically upgrade.

## [](https://www.palantir.com/docs/foundry/automate/marketplace-automate/#add-automations-to-products)Add automations to products

To add an Automation to a product, first [create a product](https://www.palantir.com/docs/foundry/foundry-devops/create-products/), then [add outputs](https://www.palantir.com/docs/foundry/foundry-devops/create-products/#add-outputs). Choose the **Add files** option to navigate to the automation from within the [Compass](https://www.palantir.com/docs/foundry/compass/overview/) filesystem and add it to your product.
