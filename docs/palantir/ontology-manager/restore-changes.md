# [](https://www.palantir.com/docs/foundry/ontology-manager/restore-changes/#review-and-restore-changes)Review and restore changes

## [](https://www.palantir.com/docs/foundry/ontology-manager/restore-changes/#review-changes-made-to-the-ontology-globally)Review changes made to the Ontology globally

Review unsaved changes made to the Ontology globally:

From the homepage sidebar, select **Unsaved changes** to view a list of all unsaved changes made by you.

![Image 7: Unsaved changes button](https://www.palantir.com/docs/resources/foundry/ontology-manager/review-restore-unsaved-changes-button.png)

Review saved changes made to the Ontology globally:

Select the **History** tab in the homepage sidebar to view a list of all saved Ontology changes with details on when the changes were made and the user who applied them.

![Image 8: History button](https://www.palantir.com/docs/resources/foundry/ontology-manager/review-restore-history-button.png)

By default, the list of changes are collapsed. You can select the ![Image 9: down arrow](https://www.palantir.com/docs/resources/foundry/ontology-manager/down-arrow.png) (down arrow) on any change to view details.

## [](https://www.palantir.com/docs/foundry/ontology-manager/restore-changes/#filter-changes-made-to-the-ontology-globally)Filter changes made to the Ontology globally

In the **Ontology history** page, you have the option to hide changes to object and link types that you do not have access to view. If this option is not enabled, you will be able to see that a change was made to the Ontology but will not be able to view additional details.

![Image 10: Hide items you cannot see](https://www.palantir.com/docs/resources/foundry/ontology-manager/review-restore-hide-changes.png?width=600)
Each entry in the edits history corresponds to a single instance of a user saving changes. You also have the option to consolidate the view by merging changes that have been made by the same author into a single entry.

## [](https://www.palantir.com/docs/foundry/ontology-manager/restore-changes/#review-changes-made-to-a-single-ontology-resource)Review changes made to a single Ontology resource

To review changes made to an Ontology resource, select the **History** tab in the Ontology resource's page. A page will be shown with the list of edits made to the resource, including the following details:

*   The unsaved changes you made to the resource.
*   All saved changes that were made to the resource with details on when the changes were made and the user who applied them.

![Image 11: Entity history button](https://www.palantir.com/docs/resources/foundry/ontology-manager/review-restore-entity-history-button.png?width=600)
At the bottom left of an Ontology resource view, a footer states when the resource was last edited and by which user.

## [](https://www.palantir.com/docs/foundry/ontology-manager/restore-changes/#restore-changes-made-to-a-single-object-type)Restore changes made to a single object type

Follow the steps below to restore an object type to an older version:

1.   Select the restore button ![Image 12: restore button](https://www.palantir.com/docs/resources/foundry/ontology-manager/restore-button.png) (anti-clockwise arrow)
2.   Select **Confirm**.

Warning

After restoring an object type to a previous version, any changes that were made after the entry you selected will be undone. The changes will be added to your working state and you will need to save your changes to the Ontology for your restore to take effect. [Learn more about saving to the Ontology.](https://www.palantir.com/docs/foundry/ontology-manager/save-changes/)
