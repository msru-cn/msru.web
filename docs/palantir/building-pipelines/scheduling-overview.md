# [](https://www.palantir.com/docs/foundry/building-pipelines/scheduling-overview/#scheduling)Scheduling

In Foundry's data integration layer, a [schedule](https://www.palantir.com/docs/foundry/data-integration/schedules/) is a key concept enabling data to stay up to date for end users who rely on data in a pipeline. Foundry's scheduling capabilities are designed to support all types of data pipelines, and provide considerable flexibility when creating scheduled builds.

Scheduled builds can be configured to run:

*   At certain times
*   When data has been updated
*   When logic has been updated
*   _Any combination of the above conditions_

Scheduled builds can be configured to build:

*   A single dataset
*   A single dataset and all its dependencies
*   All datasets that depend on a dataset
*   All datasets that connect two datasets
*   _Any combination of the above configurations_
