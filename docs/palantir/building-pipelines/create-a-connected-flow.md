# [](https://www.palantir.com/docs/foundry/building-pipelines/create-a-connected-flow/#create-a-connected-flow)Create a connected flow

In the Logic Flows App, you can:

*   **Create new** connected flows (Top right corner)
*   View existing connected flows, grouped by automation

To open the app, go to `/workspace/logic-flows`.

![Image 7: Logic Flows home page](https://www.palantir.com/docs/resources/foundry/building-pipelines/lf-app-homepage.png)

To create a connected flow in the [Compass Files Lister](https://www.palantir.com/docs/foundry/building-pipelines/compass-file-lister/), follow these steps:

1.   When creating a new connected flow, you will be presented with a dialog that allows you to set a name, project & required parameters and configuration. These are validated as it is being typed in or manually by clicking **Validate**. 

For Compass Files lister automation, you are required to set input folder and output repository. 

![Image 8: Connected Flow creation UI (filled)](https://www.palantir.com/docs/resources/foundry/building-pipelines/lf-connection-ui-filled.png)

Logic flows are _project-scoped_, meaning you must specify the project where the connected flow resource will be created. Connected flows should be saved in the same project as any parameters used to connect the flow.

1.   After saving the connected flow, it will appear in the list of connected flows. 

![Image 9: Connected flows list](https://www.palantir.com/docs/resources/foundry/building-pipelines/lf-connected-flow-list.png)

2.   To trigger the job, click **Build** in-line with the specific connected flow. A message will point you to the Builds application view where you can monitor the status of the job. 

![Image 10: Builds application showing Logic flows job](https://www.palantir.com/docs/resources/foundry/building-pipelines/lf-flow-run-builds.png)

3.   To check the results of your job, verify the pull request in the target repository view. 

![Image 11: Pull Request on output repository](https://www.palantir.com/docs/resources/foundry/building-pipelines/lf-compass-file-lister-pr.png)

4.   By heading back to Logic Flows application, you can see your connected flow, its parameters and configuration, and create a schedule from there. 

![Image 12: Connected Flow view](https://www.palantir.com/docs/resources/foundry/building-pipelines/lf-connected-flow-view.png)
