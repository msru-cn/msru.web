# [](https://www.palantir.com/docs/foundry/data-connection/marketplace-data-connection/#add-sync-or-export-to-a-marketplace-product)Add sync or export to a Marketplace product

Use [Foundry DevOps](https://www.palantir.com/docs/foundry/devops/overview/) to include your Data Connection syncs and exports in [Marketplace products](https://www.palantir.com/docs/foundry/devops/core-concepts/#product) for other users to install and reuse. [Learn how to create your first product.](https://www.palantir.com/docs/foundry/foundry-devops/create-products/)

## [](https://www.palantir.com/docs/foundry/data-connection/marketplace-data-connection/#supported-features)Supported features

Both standard [syncs](https://www.palantir.com/docs/foundry/data-connection/set-up-sync/) and [streaming syncs](https://www.palantir.com/docs/foundry/data-connection/set-up-streaming-sync/) can be included in Marketplace products. Additionally, Data Connection [exports](https://www.palantir.com/docs/foundry/data-connection/export-overview/) can be packaged alongside syncs in Marketplace products.

## [](https://www.palantir.com/docs/foundry/data-connection/marketplace-data-connection/#adding-data-connection-syncs-and-exports-to-products)Adding Data Connection syncs and exports to products

To add a Data Connection sync or export to a product, first [create a product](https://www.palantir.com/docs/foundry/foundry-devops/create-products/). Select **Add output**, then select a Data Connection source. The dialog will walk you through the process and allow you to include both syncs and exports in your Marketplace product.
