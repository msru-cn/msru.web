# [](https://www.palantir.com/docs/foundry/carbon/configuration-access/#access-configuration)Access configuration

Switch to the **Access** configuration tab (highlighted in red in the image below) to configure the [location](https://www.palantir.com/docs/foundry/carbon/configuration-access/#workspace-location) and [visibility](https://www.palantir.com/docs/foundry/carbon/configuration-access/#workspace-visibility) of a Carbon workspace, as well as [set a default workspace](https://www.palantir.com/docs/foundry/carbon/configuration-access/#default-workspace) for a user group.

![Image 5: Access tab](https://www.palantir.com/docs/resources/foundry/carbon/configure-workspace-access-tab.png?width=300)
### [](https://www.palantir.com/docs/foundry/carbon/configuration-access/#workspace-location)Workspace location

The **Location** section contains a link to the resource containing your workspace (highlighted in red in the image below). Clicking this link will allow you to change access settings or move the file in a Project.

![Image 6: Location](https://www.palantir.com/docs/resources/foundry/carbon/configure-workspace-location.png?width=300)
### [](https://www.palantir.com/docs/foundry/carbon/configuration-access/#workspace-visibility)Workspace visibility

In the workspace visibility section (highlighted in red below), [Carbon Organization Administrators](https://www.palantir.com/docs/foundry/carbon/permissions-configure/#configure-administrator-permissions) can set workspaces either as **Link only** or **Promoted**. A link-only workspace is only accessible by going directly to the URL of the workspace or opening it from a Project. A promoted workspace appears in the [Navigation Menu](https://www.palantir.com/docs/foundry/carbon/workspaces-navigation/) for all members and guests of an organization.

![Image 7: Workspace visibility](https://www.palantir.com/docs/resources/foundry/carbon/configure-workspace-workspace-visibility.png?width=300)
### [](https://www.palantir.com/docs/foundry/carbon/configuration-access/#default-workspace)Default workspace

Users can have access to more than one Carbon workspace. Thus, we recommend setting a default workspace for each user group. You can do so in the **Default workspace** section in the **Access** tab (highlighted in red below). Follow the [instructions on how to set a default workspace](https://www.palantir.com/docs/foundry/carbon/permissions-default-workspace/).

![Image 8: Set default workspace](https://www.palantir.com/docs/resources/foundry/carbon/configure-workspace-default-workspace.png?width=300)
