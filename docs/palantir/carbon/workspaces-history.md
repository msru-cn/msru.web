# [](https://www.palantir.com/docs/foundry/carbon/workspaces-history/#view-version-history)View version history

Workspace version history allows you to preview, optionally make edits, and republish previous workspace versions. This enables you to quickly return to a known working configuration if a workspace configuration update leads to errors.

## [](https://www.palantir.com/docs/foundry/carbon/workspaces-history/#versions-dialog)Versions dialog

The versions dialog is where version metadata may be viewed, with the option to select a row to set a version to preview.

![Image 5: Versions dialog](https://www.palantir.com/docs/resources/foundry/carbon/workspace-configuration-version-history-versions-dialog.png)

## [](https://www.palantir.com/docs/foundry/carbon/workspaces-history/#version-button)Version button

The versions dialog can be launched by selecting the **Version** button, located at the top of the configuration editor. The version number of the version you are currently editing is shown as the text in this button.

![Image 6: Version button](https://www.palantir.com/docs/resources/foundry/carbon/workspace-configuration-version-history-version-button.png)

### [](https://www.palantir.com/docs/foundry/carbon/workspaces-history/#unsaved-edits-indicator)Unsaved edits indicator

An asterisk (*****) will appear after the version number if there are unsaved edits.

![Image 7: Version button with edits](https://www.palantir.com/docs/resources/foundry/carbon/workspace-configuration-version-history-version-button-with-edits.png)

### [](https://www.palantir.com/docs/foundry/carbon/workspaces-history/#previewing-version)Previewing version

A **Previewing** tag is displayed next to the versions button when a version is selected from the versions dialog.

![Image 8: Version button with edits](https://www.palantir.com/docs/resources/foundry/carbon/workspace-configuration-version-history-previewing-version-button.png)
