# [](https://www.palantir.com/docs/foundry/carbon/marketplace-carbon-workspace/#add-carbon-workspace-to-a-marketplace-product)Add Carbon workspace to a Marketplace product

Use [Foundry DevOps](https://www.palantir.com/docs/foundry/devops/overview/) to include your Carbon workspaces in [Marketplace products](https://www.palantir.com/docs/foundry/devops/core-concepts/#product) for other users to install and reuse. [Learn how to create your first product.](https://www.palantir.com/docs/foundry/foundry-devops/create-products/)

## [](https://www.palantir.com/docs/foundry/carbon/marketplace-carbon-workspace/#supported-features)Supported features

Many Carbon features are supported with the exception of:

*   [Walkthroughs](https://www.palantir.com/docs/foundry/carbon/workspaces-updates/) (coming soon)
*   Module types that are not Workshop, object type, or "Link to Foundry Application"
*   Using groups for "Default object types for search"
*   "Select objects" item type

## [](https://www.palantir.com/docs/foundry/carbon/marketplace-carbon-workspace/#adding-carbon-workspaces-to-products)Adding Carbon workspaces to products

To add a Carbon workspace to a product, first [create a product](https://www.palantir.com/docs/foundry/foundry-devops/create-products/), then [add outputs](https://www.palantir.com/docs/foundry/foundry-devops/create-products/#add-outputs). Choose the **Add files** option to navigate to the workspace from within the [Compass](https://www.palantir.com/docs/foundry/compass/overview/) filesystem and add it to your product.
