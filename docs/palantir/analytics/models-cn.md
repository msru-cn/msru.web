# [](https://www.palantir.com/docs/foundry/analytics/models/#models)模型

你可以在 [Code Repositories](https://www.palantir.com/docs/foundry/integrate-models/model-asset-code-repositories/) 和 [Code Workspaces](https://www.palantir.com/docs/foundry/code-workspaces/overview/) 中创建和迭代 Foundry 模型资产。Foundry 模型是一个"逻辑容器"——它对数据知识进行编码，用于生成预测、辅助决策。模型可以保存供后续使用，提供血缘、历史记录、安全控制和分支管理。
