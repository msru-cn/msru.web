# [](https://www.palantir.com/docs/foundry/analytics/exporting-outputs/#exporting-outputs)Exporting outputs

Foundry allows qualified users to export analytical outputs for use off-platform.

Supported exports include [PDF export](https://www.palantir.com/docs/foundry/analytics/exporting-outputs/#pdf-export), [export of visualizations as images](https://www.palantir.com/docs/foundry/analytics/exporting-outputs/#visualization-export), and [export as CSV or XLSX](https://www.palantir.com/docs/foundry/analytics/exporting-outputs/#data-export).

## [](https://www.palantir.com/docs/foundry/analytics/exporting-outputs/#pdf-export)PDF export

Notepad supports downloading documents to PDF with the ability to customize content such as page orientation, headers and footers, and individual embed (charts, tables, etc.) appearance.

[Learn how to get started with Notepad.](https://www.palantir.com/docs/foundry/notepad/getting-started/)

## [](https://www.palantir.com/docs/foundry/analytics/exporting-outputs/#visualization-export)Visualization export

You can export individual visualizations as images in Contour, Quiver, and Code Workbook.

In Contour and Quiver, look for the ![Image 8: Download icon](https://www.palantir.com/docs/resources/foundry/analytics/download-button.png?width=30px) button (**Download chart as image**) in the top right of any chart, as shown below.

![Image 9: Screenshot of Contour download button](https://www.palantir.com/docs/resources/foundry/analytics/export-contour-image.png)

In Code Workbook, choose **Download image** from the action menu of any visualization node as shown below.

![Image 10: Screenshot of Code Workbook download image action item](https://www.palantir.com/docs/resources/foundry/analytics/export-code-workbook-image.png?width=400px)
## [](https://www.palantir.com/docs/foundry/analytics/exporting-outputs/#data-export)Data export

You can export analytical results as CSV and/or XLSX in Contour, Quiver, and Code Workbook.

### [](https://www.palantir.com/docs/foundry/analytics/exporting-outputs/#contour)Contour

There are two ways to export data from Contour, both of which have an export limit of 100,000 rows:

*   Add an **Export** board to your analysis path.

![Image 11: contour export board](https://www.palantir.com/docs/resources/foundry/analytics/export-contour-board.png)

*   Alternatively, you can select the relevant board in your analysis and open the table panel, then select your desired export option.

![Image 12: contour export table](https://www.palantir.com/docs/resources/foundry/analytics/export-contour-table.png)

### [](https://www.palantir.com/docs/foundry/analytics/exporting-outputs/#quiver)Quiver

To export data from a Quiver analysis, select **Download as CSV** from the action menu for any card.

![Image 13: quiver export card](https://www.palantir.com/docs/resources/foundry/analytics/export-quiver-card.png)

### [](https://www.palantir.com/docs/foundry/analytics/exporting-outputs/#code-workbook)Code Workbook

To export data from a Code Workbook, select **Download as CSV** from the action menu for transforms that are saved as datasets. The default export limit is 100,000 rows. Note that the results of unpersisted transforms cannot be downloaded as CSV. [Learn more about persisted and unpersisted transforms in Code Workbook.](https://www.palantir.com/docs/foundry/code-workbook/optional-data-persistence/)

![Image 14: code workbook export dataset](https://www.palantir.com/docs/resources/foundry/analytics/export-code-workbook.png)
