# [](https://www.palantir.com/docs/foundry/analytics/exporting-outputs/#exporting-outputs)导出输出

Foundry 允许有权限的用户将分析结果导出到平台外使用。

支持的导出方式包括 [PDF 导出](https://www.palantir.com/docs/foundry/analytics/exporting-outputs/#pdf-export)、[可视化图表导出为图片](https://www.palantir.com/docs/foundry/analytics/exporting-outputs/#visualization-export) 和 [CSV/XLSX 导出](https://www.palantir.com/docs/foundry/analytics/exporting-outputs/#data-export)。

## [](https://www.palantir.com/docs/foundry/analytics/exporting-outputs/#pdf-export)PDF 导出

Notepad 支持将文档下载为 PDF，可自定义页面方向、页眉页脚，以及各个嵌入内容（图表、表格等）的样式。

[了解 Notepad 入门。](https://www.palantir.com/docs/foundry/notepad/getting-started/)

## [](https://www.palantir.com/docs/foundry/analytics/exporting-outputs/#visualization-export)可视化导出

你可以在 Contour、Quiver 和 Code Workbook 中将单个可视化图表导出为图片。

在 Contour 和 Quiver 中，找到任意图表右上角的 ![Image 8: Download icon](https://www.palantir.com/docs/resources/foundry/analytics/download-button.png?width=30px) 按钮（**Download chart as image**），如下图所示。

![Image 9: Screenshot of Contour download button](https://www.palantir.com/docs/resources/foundry/analytics/export-contour-image.png)

在 Code Workbook 中，在任意可视化节点的操作菜单中选择 **Download image**，如下图所示。

![Image 10: Screenshot of Code Workbook download image action item](https://www.palantir.com/docs/resources/foundry/analytics/export-code-workbook-image.png?width=400px)
## [](https://www.palantir.com/docs/foundry/analytics/exporting-outputs/#data-export)数据导出

你可以在 Contour、Quiver 和 Code Workbook 中将分析结果导出为 CSV 和/或 XLSX。

### [](https://www.palantir.com/docs/foundry/analytics/exporting-outputs/#contour)Contour

Contour 有两种导出方式，导出上限均为 10 万行：

*   在分析路径中添加 **Export** 看板。

![Image 11: contour export board](https://www.palantir.com/docs/resources/foundry/analytics/export-contour-board.png)

*   或者选中分析中的相关看板，打开表格面板，然后选择导出方式。

![Image 12: contour export table](https://www.palantir.com/docs/resources/foundry/analytics/export-contour-table.png)

### [](https://www.palantir.com/docs/foundry/analytics/exporting-outputs/#quiver)Quiver

在 Quiver 分析中，在任意卡片的操作菜单中选择 **Download as CSV**。

![Image 13: quiver export card](https://www.palantir.com/docs/resources/foundry/analytics/export-quiver-card.png)

### [](https://www.palantir.com/docs/foundry/analytics/exporting-outputs/#code-workbook)Code Workbook

在 Code Workbook 中，对已保存为数据集的转换，在操作菜单中选择 **Download as CSV**。默认导出上限为 10 万行。注意，未持久化的转换结果无法下载为 CSV。[了解更多关于 Code Workbook 中的持久化与非持久化转换。](https://www.palantir.com/docs/foundry/code-workbook/optional-data-persistence/)

![Image 14: code workbook export dataset](https://www.palantir.com/docs/resources/foundry/analytics/export-code-workbook.png)
