# [](https://www.palantir.com/docs/foundry/analytics/overview/#analytics)分析

Foundry 为组织中的各类用户提供分析能力，并与 Foundry Ontology 深度集成。开箱即用，Foundry 包含点击式和代码式工具，支持表格分析、自上而下的可视化分析、地理空间分析、时间序列分析等。Foundry 的分析不仅限于传统的"只读"模式，还能将数据回写到 Ontology，在统一的安全、血缘和治理模型中产生有价值的新洞察。

## [](https://www.palantir.com/docs/foundry/analytics/overview/#core-applications)核心应用

Foundry 的核心分析应用包括：

*   [**Contour**](https://www.palantir.com/docs/foundry/contour/overview/)：自上而下的分析工具，用于快速探索大规模表格数据、通过可视化转换生成新数据集、创建图表。
*   [**Quiver**](https://www.palantir.com/docs/foundry/quiver/overview/)：多模式图表应用，支持对象驱动分析、时间序列驱动分析、点击式机器学习和仪表板构建。
*   [**Code Workbook**](https://www.palantir.com/docs/foundry/code-workbook/overview/)：融合数据工程和数据科学的应用，支持 Python、R 或 SQL 驱动的快速转换构建、机器学习模型训练等。
*   [**Notepad**](https://www.palantir.com/docs/foundry/notepad/overview/)：集成解决方案，可将 Foundry 各处的动态分析、可视化和运营内容嵌入到格式化文本和媒体中。
*   [**Fusion**](https://www.palantir.com/docs/foundry/fusion/overview/)：电子表格驱动的应用，将表格计算与 Foundry Ontology 和对象驱动查询系统的能力结合起来。

## [](https://www.palantir.com/docs/foundry/analytics/overview/#analytical-connectivity)分析工具连接

Foundry 还设计为能与现有分析工具深度集成。组织可以通过标准 API 和接口将商业智能、可视化及其他分析应用连接到 Foundry。集成选项包括：

*   开箱即用的连接器，如 **[Power BI®](https://www.palantir.com/docs/foundry/analytics-connectivity/power-bi-overview/)** 和 **[Tableau](https://www.palantir.com/docs/foundry/analytics-connectivity/tableau-overview/)**。
*   **[REST API](https://www.palantir.com/docs/foundry/api/general/overview/introduction/)**，用于灵活的按需连接。
*   **[ODBC 和 JDBC 驱动](https://www.palantir.com/docs/foundry/analytics-connectivity/odbc-jdbc-drivers/)**，用于通用连接。
*   **[Python ↗](https://github.com/palantir/palantir-python-sdk)** 和 **[R ↗](https://github.com/palantir/palantir-r-sdk)** SDK，用于连接数据科学工具。
*   Microsoft Report Builder 和 Excel 等工具的引导式集成，基于标准接口。

[了解 Foundry 中可执行的分析类型。](https://www.palantir.com/docs/foundry/analytics/types-of-analysis/)
