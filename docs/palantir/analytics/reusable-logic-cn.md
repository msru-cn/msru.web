# [](https://www.palantir.com/docs/foundry/analytics/reusable-logic/#reusable-logic)可复用逻辑

在分析应用中，你可以保存部分逻辑供其他用户复用。这有助于减少重复工作、加快价值交付，并让用户能使用领域专家或技术更强的同事创建的逻辑。

## [](https://www.palantir.com/docs/foundry/analytics/reusable-logic/#contour)Contour

在 Contour 中，你可以[保存表达式](https://www.palantir.com/docs/foundry/contour/expressions-overview/)，轻松在不同分析路径间复用逻辑，也可以与他人共享。保存的表达式可用于创建或替换列，或执行聚合。[了解更多关于 Contour。](https://www.palantir.com/docs/foundry/contour/overview/)

![Image 4: Example screenshot of Contour saved expressions](https://www.palantir.com/docs/resources/foundry/analytics/contour-saved-expression.png)

## [](https://www.palantir.com/docs/foundry/analytics/reusable-logic/#quiver)Quiver

Quiver 中的[可视化函数](https://www.palantir.com/docs/foundry/quiver/visual-functions-overview/)由一个或多个 Quiver 卡片组成，负责加载、组合和转换数据。可视化函数会自动将一组逻辑步骤应用到 Quiver 分析中的数据输入，也可被他人在其分析中使用。[了解更多关于 Quiver。](https://www.palantir.com/docs/foundry/quiver/overview/)

![Image 5: Example screenshot of Quiver visual functions](https://www.palantir.com/docs/resources/foundry/analytics/quiver-visual-function.gif)

## [](https://www.palantir.com/docs/foundry/analytics/reusable-logic/#code-workbook)Code Workbook

Code Workbook 模板通过简洁的表单界面封装代码逻辑，让技术高手能不太熟悉的写代码的用户协作。用户选择的值会替换到模板中，然后像工作簿中的其他转换一样运行。任何可以用代码创建的转换，如 Matplotlib 或 Plotly 可视化，都可以用代码模板构建。[了解更多关于 Code Workbook。](https://www.palantir.com/docs/foundry/code-workbook/overview/)
