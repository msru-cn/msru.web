# [](https://www.palantir.com/docs/foundry/analytics/reporting/#reporting)报告

在 Foundry 中，"报告"指的是创建带有注释的时间点内容，用于平台内共享或下载。如果你想创建交互式内容供他人直接操作，建议使用 Foundry 的[仪表板产品](https://www.palantir.com/docs/foundry/analytics/dashboards/)。

## [](https://www.palantir.com/docs/foundry/analytics/reporting/#notepad)Notepad

Notepad 是 Foundry 的报告工具。通过 Notepad，你可以创建实时更新和静态（"时间点"）文档、添加注释、在平台内共享文档，以及导出为 PDF。

![Image 3: Example screenshot of the Notepad application](https://www.palantir.com/docs/resources/foundry/analytics/reporting-notepad.png)

Notepad 的主要功能：

*   易用的文档创建和编辑体验。
*   支持从多种 Foundry 来源添加内容，包括 Quiver、Contour、Code Workbook 和 Object Explorer。
*   支持带动态输入的文档模板。
*   可自定义的 PDF 导出。

[了解 Notepad 入门。](https://www.palantir.com/docs/foundry/notepad/overview/)

## [](https://www.palantir.com/docs/foundry/analytics/reporting/#reports-sunset)Reports [已淘汰]

已淘汰

Reports 已进入[淘汰](https://www.palantir.com/docs/foundry/platform-overview/development-life-cycle/)阶段，将在未来被弃用。完整支持仍然可用。之前保存的报告仍可只读查看，无需转换或迁移到新格式，除非需要编辑。建议将工作流迁移到其他应用和工具。

![Image 4: Example screenshot of the Foundry Reports application](https://www.palantir.com/docs/resources/foundry/analytics/reporting-reports.png)

旧版 Foundry Reports 应用同时支持实时仪表板和静态报告场景。但其他 Foundry 工具对这些工作流有更好的支持和更丰富的功能。对于大多数仪表板和报告场景，推荐以下产品：

*   **Contour 仪表板**：适合由 Contour 分析生成的内容。相比 Reports，Contour 仪表板交互性更强，支持图表间联动筛选，以及拖拽式仪表板构建。[了解更多 Contour 仪表板入门。](https://www.palantir.com/docs/foundry/contour/dashboards-overview/)
*   **Quiver 仪表板**：适合由 Quiver 分析驱动的内容。Reports 不支持嵌入大多数 Quiver 可视化类型。[了解更多 Quiver 仪表板入门。](https://www.palantir.com/docs/foundry/quiver/dashboards-overview/)
*   **Notepad**：适合跨产品内容和大多数 Foundry 报告场景，详见[上文](https://www.palantir.com/docs/foundry/analytics/reporting/#notepad)。[了解更多 Notepad 入门。](https://www.palantir.com/docs/foundry/notepad/overview/)

如果你需要创建一个整合多个来源内容的仪表板——比如一个 Contour 分析加一个 Code Workbook，或两个 Contour 分析——可能仍然需要使用 Reports。[了解更多 Reports 入门](https://www.palantir.com/docs/foundry/reports/overview/)。
