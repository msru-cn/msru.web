# 最终用户平台使用许可 (EULA)

本《最终用户使用许可》（"EULA"）是您实体或您代表的企业（以下统称"客户"或"被许可方"）与 MSRU Inc.（以下统称"MSRU"或"许可方"）之间关于 MSRU Platform 系列核心引擎及商业版插件的合法契约。

## 当你在终端里敲下 `pnpm install msru-core`

或者是正式签署了《商业集成交付 SA》时，您即被视为同意无条件接受以下工业级授权条款的约束。

### 一、 商业许可定界 (License Grant)

MSRU 平台提供兼顾敏捷创新的**核心开源版 (Community OSS)** 以及旨在承载超大吞吐量与严苛安全的**白金企业授权版 (Enterprise Edition)**。

对于企业级商用授权 (Perpetual / Subscription Node-locked)：

1. **物理生产域约束：** 被授权的控制节点仅限用于 MSRU 合同附件中约定的实体物理车间或指定云租户 VPC 内。未经官方认证组建跨国或跨主体的**联机联邦集群**将被视作极其恶劣的授权溢出行为。
2. **二次商用与魔改：** MSRU 底层核心引擎的指令集及微服务注册中心源码。在未获得定制研发特许证书（OEM/VAR）前，严禁将 MSRU 的封装组件用于打包二次转售 (Resale) 或者白标化 (White-labeling) 作为您自己独立研发的平台级竞品流入市场。

### 二、 反向工程隔离 (Reverse Engineering)

您有权且被鼓励使用我们提供的丰富 OpenAPI 或 GraphQL 终端节点来集成企业已有的 PDM、PLM 等遗留系统。但我们严正宣告：

* 禁止一切针对 MSRU 闭源商业插件（如：AI 质检大模型算法组件、APS 高级多阶段并行排程引擎引擎）的反向编译、脱壳或恶意旁路监听核心内存队列的数据。违者 MSRU 将单边行使一键阻断许可握手的权力。

### 三、 测试与验收条款 (UAT)

为了避免业务停顿，我们要求所有从旧 ERP/MES 过渡到 MSRU 全新底座的迁移流，必须先在隔离的 UAT 测试桩环境中经历至少一个自然周的面包板压测。如果未经 UAT 签字直接拉起到生产环境所造成的烂账、脏数据或停机，由此引发的连带工厂损失不由 MSRU 最终承担。
