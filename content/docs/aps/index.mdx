# APS 高级排程概览

在充满不确定性的生产环境中，**MSRU | APS (Advanced Planning and Scheduling)** 充当着工厂的“超级指挥官”。它致力于在有限的资源约束下，寻找效率与交期的最优平衡点。

### 核心价值：从“靠感觉”到“靠算法”

传统的 Excel 排程难以应对瞬息万变的订单变更和设备故障。MSRU | APS 提供：

-   **有限产能约束 (FCS)**：基于机台工时、模具寿命、人员技能的真实上限进行排程，杜绝无效计划。
-   **智能模拟与预演**：在正式下达工单前，模拟“插单”、“零件短缺”或“设备检修”对整体产线的影响。
-   **动态重新排程**：当底层 MES 反馈生产异常时，APS 可以一键触发重新全局计算，将损失降至最低。

### 关键能力

-   **[算法模型](../usage/modules#排程引擎)**：支持多种启发式算法与约束推演引擎。
-   **[资源大图](../usage/overview)**：甘特图表形式直观展现各产线、各班次的饱和度。
-   **[物料平衡](../wms/index)**：与 WMS 实时联动，确保生产计划不会因为“缺料”而停罢。
