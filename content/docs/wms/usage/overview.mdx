# 使用概览：数字化工位的物流实操

一个 WMS 系统的成败，往往取决于其在仓库一线工人手中的易用性。**MSRU | WMS** 将复杂的物流逻辑封装在极简的交互界面之下，旨在让每一位操作员都能以“零错误率”执行高强度的物流任务。

本指南将通过实战视角，带您走过一个典型数字化仓库的日常作业路径。

<Callout type="info" title="针对工业现场的 UI 优化">
  考虑到仓库内的复杂环境（光线暗、戴手套、单手操作），MSRU 的 PDA 客户端采用了大色块交互设计，并支持扫描成功/失败的震动与音频即时反馈。
</Callout>

## 2. 关键作业路径：标准单据流转 (SOP)

从一笔“采购订单”进入系统开始，您的数字化作业便已启动。

<Steps>
  <Step>
    ### 指令接收 (Task Dispatch)
    操作员登录 PDA。系统会根据当前的**任务优先级（Priority）**与**人员位置分布**，自动推送最近的作业任务，无需人工派工。
  </Step>
  <Step>
    ### 物理扫码校验 (Verification)
    无论是收货还是拣选，每一个动作都必须经过条码/RFID 校验。如果物料批次不正确，系统会立即锁定流程并弹出红色警告。
  </Step>
  <Step>
    ### 路径引导 (Path Guidance)
    PDA 屏幕会实时显示下一个目标库位的 3D 缩略图及其在巷道中的具体高度，减少“找货”损耗。
  </Step>
  <Step>
    ### 状态即时同步
    确认动作完成的瞬间，全库位的“账面余额”完成更新。管理看板会同步显示该订单的“物流进度条”。
  </Step>
</Steps>

## 3. 看板与监控：仓库的“塔台”视图

管理人员通过以下三个标签页掌控全仓。

<Tabs items={['实时动效', '单据中心', '效能看板']}>
  <Tab value="实时动效">
    ### 3D 库位填充率 (Fill Rate)
    通过颜色深浅展示库位的饱和度。红色区域表示需要进行“库位重排”以释放空间。
  </Tab>
  <Tab value="单据中心">
    ### 挂起单据追踪
    实时列出所有超期未收货或未拣选的订单。支持“一键催办”并推送到相关工人的 PDA 终端。
  </Tab>
  <Tab value="效能看板">
    ### 工人绩效 (Gamification)
    展示当班的拣选吨位、准确率排行。有助于激发一线的作业积极性。
  </Tab>
</Tabs>

## 5. 现场异常处理 FAQ

<Accordions>
  <Accordion title="库位上显示的货已经拣空了，但 PDA 提示还有怎么办？">
    **原因**: 可能发生了“实物盘亏”或“被误发”。
    **解决**: 在 PDA 上点击 `报告不符`。系统会立即冻结该库位，并自动生成一条“紧急补货/盘点单”通知领班，同时系统会自动为您重分发另一个可用库位，确保拣选流水线不中断。
  </Accordion>
  <Accordion title="无线网络信号不好，作业会丢数据吗？">
    **保障**: MSRU 边缘代理支持 **“本地断点续传”**。在网络盲区，PDA 会将流水暂存在本地内存中。一旦您推车进入有信号的巷道口，数据会自动异步上传，无需手动重刷。
  </Accordion>
</Accordions>
