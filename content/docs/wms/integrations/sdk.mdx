# SDK 使用指南：构建可编程工业物流

对于普通的业务系统，[REST API](./api) 已经足够；但在处理 **“高频、强一致、设备级联动”** 的智慧物流场景时，SDK 是唯一的专业选择。MSRU | WMS SDK 允许开发者将自定义逻辑注入到 WMS 的核心运行进程中，实现内存级的数据交换。

无论是开发一个全新的 AGV 控制驱动，还是实现一个复杂的“防错匹配逻辑”，SDK 都是您强大的支点。

<Callout type="info" title="边缘优先的 SDK 架构">
  MSRU SDK 原生支持 **“进程内 (In-Process)”** 调用。这意味着当您的 PDA 扫描物料时，自定义的校验插件可以在 0.5 毫秒内完成判定，而无需等待跨网络的 API 往返。
</Callout>

## 2. 核心架构：基于钩子 (Hooks) 的双向联动

开发者通过注册 `Hooks` 来侦听并拦截 WMS 的核心流程。

<Tabs items={['代码示例 (TS)', '生命周期钩子', '性能指标']}>
  <Tab value="代码示例 (TS)">
    ```typescript showLineNumbers
    import { WmsClient, StockEvent } from "@msru/wms-sdk";

    const wms = new WmsClient({ siteId: "HUB-SH-01" });

    // 拦截出库扣减流程，增加自定义的企业合规校验
    wms.on(StockEvent.BEFORE_DISPATCH, async (context) => {
      const isCompliant = await checkInternalPolicy(context.sku);
      if (!isCompliant) {
        throw new Error("COMPLIANCE_RESTRICTION: Item flagged for export control");
      }
    });
    ```
  </Tab>
  <Tab value="生命周期钩子">
    | 钩子名称 | 触发点 | 典型用途 |
    | :--- | :--- | :--- |
    | `onBarcodeScan` | 条码数据刚解析时 | 实现私有条码规则转换 |
    | `onLocationAssign` | 算法分库位前 | 注入自定义空间约束 |
    | `onBalanceSync` | 云端数据聚合时 | 实现自定义的冲突解决算法 |
  </Tab>
  <Tab value="性能指标">
    通过进程内通讯，SDK 的调用开销被限制在极小范围内：
    <MathEquation 
      inline={false} 
      formula={String.raw`Latency_{logic} = T_{user\_fn} + \underbrace{\epsilon}_{\text{Platform Overhead} < 0.1ms}`} 
    />
  </Tab>
</Tabs>

## 3. 高级功能：边缘侧本地持久化 (Storage Context)

在“断网自治”期间，SDK 允许插件使用具有事务保障的本地存储。

<Steps>
  <Step>
    ### 环境申明
    在插件清单 `manifest.yaml` 中申明所需的磁盘配额与数据库类型（如 SQLite 或 RocksDB）。
  </Step>
  <Step>
    ### 状态暂存 (State Persistence)
    在网络离线时，通过 SDK API 将 PDA 扫描的中间状态保存在边缘节点，防止掉电丢失。
  </Step>
  <Step>
    ### 数据合并策略
    网络恢复后，SDK 将触发 `onRejoinCluster` 事件，引导您的代码完成本地数据与云端全局状态的合并。
  </Step>
</Steps>

## 5. 开发建议与避坑指南

<Accordions>
  <Accordion title="为什么我的插件导致边缘 Agent 重启？">
    **原因**: 本地插件与 WMS 共享部分内存空间。如果您的代码发生了严重的内存溢出或未捕获的恐慌（Panic），防护机制会强制重启进程。
    **解决**: 建议在 Rust 开发中严格遵守生命周期，或在 TS 代码中使用 `try-catch` 闭包包裹所有的 Hook 逻辑。
  </Accordion>
  <Accordion title="SDK 插件是否支持动态加载？">
    支持。MSRU WMS 边缘代理实现了 **“热插拔 (Hot-Swapping)”** 机制。通过 `msru-cli plugin load` 指令，无需停机即可完成逻辑热更新。
  </Accordion>
</Accordions>
