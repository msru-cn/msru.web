## 附加章节 1：分层架构深度解析 (Layer-by-Layer Architecture)

MSRU 的技术基石在于其独特的“四级分层模式”。这种模式确保了系统在从单一传感器到全球云端节点的高度一致性。

### L0：感知执行层 (Physical Actuation)
这一层由传统的 PLC (西门子、三菱等)、机器人臂以及 MSRU 自研的传感器组成。L0 层产生了所有的原始信号。MSRU 通过自研的**硬件加速引擎**，在物理连接处就完成了数据的初步对齐，解决了多厂家、多协议接口导致的电信号同步差问题。

### L1：边缘智能层 (Edge Intelligence)
这是 MSRU 的核心竞争优势所在。在边缘侧，我们部署了轻量化的 K3s 集群。边缘网关不仅仅是转发数据，它还在进行：
- **实时脱敏与脱离**：保护企业核心工艺诀窍，不随便上云。
- **高速本地联动**：例如，当压力变送器侦测到毫秒级的波峰异常，边缘节点会在不经过云端的情况下直接切断供料，实现“硬关断”。此时的计算延时通常维持在 **5ms - 10ms**。

### L2：平台汇聚层 (Universe Aggregator)
这是 MSRU 的云端大脑，采用高并发的消息总线架构。它负责：
- **全球资产索引**：能够快速检索到全球 50 个工厂中的任何一笔质量记录。
- **物模型编译**：将 L1 层上报的结构化数据与业务语义进行二次结合。

### L3：应用生态层 (Application Ecosystem)
在这一层，MSRU 开放了丰富的 API 与 Webhook，允许第三方系统（如 SAP、Oracle ERP）无缝调用实时生产数据。我们鼓励合作伙伴基于 MSRU 内核开发特定的垂直行业应用，形成一个“工业版 App Store”。
