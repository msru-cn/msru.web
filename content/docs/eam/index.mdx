# EAM 设备资产管理概览

**MSRU | EAM (Enterprise Asset Management)** 致力于将工厂内的机器从“昂贵的黑盒”转化为“健康的生产力”。它涵盖了设备从采购、安装到运维、退役的全生命周期管理。

### 核心使命：预防性维护

我们的目标是消灭“意外停机”。通过 MSRU 底层的 IoT 数据支撑，EAM 实现了从“坏了才修”到“预防性维护”的跃迁：

-   **设备档案中心**：每一台设备都有其专属的数字履历，包括技术手册、变更记录与易损件清单。
-   **工单式巡检**：标准化的点检、保养计划自动推送到维修人员移动端，确保运维动作标准化。
-   **OEE 实时统计**：自动计算设备综合效率，识别导致停顿的潜在根本原因。

### 模块亮点

-   **[备品备件](../usage/modules#备件库)**：与 WMS 联动，确保关键零件在故障发生前补仓到位。
-   **[维修知识库](../integrations/ai)**：引入 AI 对历史故障记录进行分析，为维修任务提供即时解决方案建议。
-   **[IoT 状态监测](../iot/index)**：实时监控电机电流、温度、振动等指标，实现预警预测。
