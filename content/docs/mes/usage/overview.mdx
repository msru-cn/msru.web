# 使用概览：数字化工位的日常操作指南

MSRU | MES 的成功不在于后端架构的精妙，而在于产线每一位操作工是否能顺畅、无误地与其交互。本页面旨在为终端用户提供一个清晰、直观的操作路径，帮助您快速熟悉数字化工位的核心业务场景。

在 MSRU 体系中，传统的纸质报工单已被 **智能终端（Smart Terminal）** 所取代，所有交互都遵循“扫码即录入、操作即追溯”的极简原则。

<Callout type="info" title="极致的 UI 体验">
  考虑到工业现场复杂的环境（如：戴手套操作、高噪音、强光），MSRU 的工人端 UI 采用了大尺寸按钮与强对比色设计，并支持语音播报关键工艺提醒。
</Callout>

## 2. 核心操作路径：标准节点流转

一个典型的数字化工位操作流程如下：

<Steps>
  <Step>
    ### 签到与认证
    操作工在工位终端扫描工卡或通过面部识别登录。系统会自动根据您的 **技能矩阵 (Skill Matrix)** 判断您是否具备操作本工序的资质。
  </Step>
  <Step>
    ### 指令接收与物料校验
    系统自动显示当前优先级最高的工单。工人扫描原材料或半成品条码，系统实时执行 **防错（Poka-yoke）** 校验，确保“对的人、在对的时间、用对的料”。
  </Step>
  <Step>
    ### 执行与自动报工
    加工完成后，点击“完工”。如果是自动化产线，PLC 会在工序完成瞬时通过 MSRU 边缘代理自动触发报工，无需人工干预。
  </Step>
  <Step>
    ### 异常填报 (可选)
    加工过程中发生任何品质异常或设备微停机，通过简单的“点选式”菜单（非文字输入）进行秒级上报。
  </Step>
</Steps>

## 3. 基于 Tabs 的功能视窗切换

在同一个工位终端，工人可以通过标签页快速访问不同的数字化资源。

<Tabs items={['实时任务', '电子 SOP', '个人绩效']}>
  <Tab value="实时任务">
    ### 任务清单 (Task Backlog)
    显示当前待加工数量、待投料明细以及下一工序的堆积状态（下游瓶颈预警）。
  </Tab>
  <Tab value="电子 SOP">
    ### 3D 交互式说明书
    支持通过旋转、放大查看具体的装配位置。如果工艺发生变更，系统会强制弹出 **“已阅读并确认”** 对话框，确保变更 100% 宣贯到位。
  </Tab>
  <Tab value="个人绩效">
    ### 实时计数与达成率
    展示当前班次的 OEE、良率及个人计件工资预估，激发一线的生产积极性。
  </Tab>
</Tabs>

## 5. 常见问题排查 (FAQ)

<Accordions>
  <Accordion title="扫描条码时提示“物料不匹配”怎么办？">
    1.  检查是否拿错了物料。
    2.  检查物料是否已在仓库模块中被“冻结”或“锁定”。
    3.  联系领班检查当前的 BOM 版本是否发生了紧急更新。
  </Accordion>
  <Accordion title="报工完成后，发现数量录入错了能修改吗？">
    出于数据完整性考虑，一旦完工确认后，普通操作工无权修改。需联系领班在后台的 `生产数据审计` 模块中执行“红冲（Reverse Correction）”操作，该动作会被系统完整记录审计轨迹。
  </Accordion>
</Accordions>
