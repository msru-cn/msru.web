# 系统设置：多尺度生产参数调优

MSRU | MES 的强大不仅源于其架构，更源于其极其精细的配置能力。在一个拥有数千种物料与数百条产线的复杂工厂中，如何通过参数化管理替代硬编码，是衡量一个系统“数字化成熟度”的核心指标。

本页面将指导您如何配置 MSRU | MES 的核心参数，以实现生产的高效率与数据的高一致性。

<Callout type="info" title="配置作用域">
  MSRU 采用 **级联配置模式**：全局设置 (Global) > 厂区设置 (Site) > 产线设置 (Line) > 边缘节点设置 (Edge)。低层级的配置将自动覆盖高层级的默认值。
</Callout>

---

## 2. 物料多尺度建模 (Material Meta-Modeling)

物料不仅仅是一个 ID，它包含了生产过程中所有的约束条件。MSRU 允许您利用 **自定义属性 (Custom Attributes)** 来扩展物料模型。

<Tabs items={['属性定义', '属性级联代码', '计算模型']}>
  <Tab value="属性定义">
    ### 关键质量参数 (KPC)
    您可以为 CPU 芯片等关键物料增加 `v_core_voltage`（核心电压）属性。在 [OP-20] 工序报工时，系统会强制要求读取并校验该参数是否在预设的 1.1V - 1.3V 区间内。
  </Tab>
  <Tab value="属性级联代码">
    ```json showLineNumbers
    {
      "material_id": "MSRU-CHIP-V1",
      "ext_props": {
        "is_esd_sensitive": true,
        "bake_duration_hrs": 48,
        "max_floor_life_mins": 240
      }
    }
    ```
  </Tab>
  <Tab value="计算模型">
    当物料暴露在空气中超过 `max_floor_life_mins` 时，MSRU 调度器会自动触发 **“失效锁定 (Life-cycle Lockout)”**，计算逻辑如下：
    <MathEquation 
      inline={false} 
      formula={String.raw`T_{remain} = L_{max} - (T_{now} - T_{unseal}) > 0 \implies \text{VALID}`} 
    />
  </Tab>
</Tabs>

## 5. 权限与集成配置 (RBAC)

MES 的安全性取决于谁能在什么时候操作。在 `配置 > 权限控制` 中：

<Steps>
  <Step>
    ### 定义角色矩阵
    创建 `OPERATOR`（操作工）、`SUPERVISOR`（班组长）与 `MAINTAINER`（维护员）角色。
  </Step>
  <Step>
    ### 绑定硬件标识
    不仅通过账号验证，还支持将权限与物理工位的 **MAC 地址** 或 **PDA 设备 ID** 绑定，防止权限在非受控区域溢用。
  </Step>
  <Step>
    ### 开启审计日志 (Audit Trail)
    开启 FDA 21 CFR Part 11 兼容模式，强制记录所有参数修改前后的值及修改原因。
  </Step>
</Steps>
