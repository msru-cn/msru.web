# Framework 架构体系

**MSRU Framework** 是专为构建高性能、高可靠“工业级软件”而设计的技术底座。它基于 **Turborepo** 实现高扩展性的 Monorepo 工作区管理，并深度整合了 **Next.js**、**Shadcn UI** 与 **Tailwind CSS**。

### 核心架构哲学

工业级软件对**确定性**、**实时性**和**扩展性**有着极报要求：

1.  **分层治理**：严格隔离 UI 展示层（Packages/UI）、核心业务逻辑（Packages/Core）与基础设施配置，确保系统性稳定。
2.  **插件式扩展**：支持基于微服务与 Web 技术的动态功能扩展，允许在不破坏核心引擎的前提下定制业务逻辑。
3.  **极速 DX (开发者体验)**：利用 Turbopack 指令与现代化工具链，实现秒级热更新，加速工业场景的快速迭代。
